## Tools

- **Claude (Anthropic), chat:** challenge analysis, the first draft of the project plan, research notes on comparison processing and 3D sky options.
- **Claude Code (Anthropic), coding agent:** used by all three team members for most of the code and the internal documents, always on a team member's instruction.

## What AI was used for

- **Planning documents:** the project plan, decision log and shared team memory (`docs/`) were drafted with AI and reviewed by the team. Decisions were made by people; AI helped record them.
- **Code:** the sky view, the analysis panel (blink, difference, stack), the five additional analyses, the data access layer (IRSA SIA2, DataLink, AWS byte-range reads, Gaia queries) and the database setup were written with Claude Code under each member's direction. Team members chose the methods, checked results against known values, and reviewed the changes.
- **Verification support:** AI ran checks we asked for, such as comparing measured proper motions with Gaia DR3 (Barnard's Star 10.39″/yr measured vs. Gaia), decoding quality flags against IRSA cutouts, and confirming quoted numbers in the cited papers' text.
- **Not used for:** no AI-generated images, video, audio or data are shown as observations. All images in the tool are real telescope data, and the one sonification (Sky Sonata) is computed by fixed rules from real pixels, not generated by AI.
