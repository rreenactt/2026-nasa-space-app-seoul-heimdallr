HEIMDALLR is a public web tool for seeing how the sky changes in NASA's SPHEREx survey. Click any point of an all-sky view or type coordinates, and the tool plays that patch's SPHEREx DR1 images as a blink animation, with difference and stack views. Frames come only from the same detector at matching wavelengths, because SPHEREx's filters change wavelength across every image, and all sit on a fixed sky grid so motion is never centered away. Gaia DR3 positions moved to each visit's date separate known stars from anything new.

Our team searches SPHEREx for candidates, places where a source seems to have moved since 2MASS imaged the same sky 25 years earlier, and keeps the list growing; the public checks them. The first survey of 75,756 fields found 262 known moving stars and 41 unidentified candidates. Anyone can rate a place Moving, Not moving, or Noise or artifact, and the list changes as ratings build up: strongly supported candidates become noteworthy, rejected ones leave the queue, and new survey runs can add more. Five additional analyses go further, from 25-year comparisons with 2MASS, WISE and NEOWISE to spectra of interstellar comet 3I/ATLAS. Results are always called candidates, and missing data is shown as missing.
