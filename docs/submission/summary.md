HEIMDALLR is a public web tool for seeing how the sky changes in NASA's SPHEREx survey. Visitors browse an all-sky view, click any point or type its coordinates, and the tool plays that patch's SPHEREx DR1 images as a blink animation, with difference and stack views. Frames come only from the same detector at matching wavelengths, because SPHEREx's filters change wavelength across every image, and all sit on a fixed sky grid so motion is never centered away. Gaia DR3 positions moved to each visit's date separate known stars from anything new.

Our team runs the candidate search and keeps adding to it; the public checks it. The first survey compared SPHEREx with 2MASS across 25 years in 75,756 fields and found 262 known moving stars and 41 unidentified candidates for review. Anyone can rate a place Moving, Not moving, or Noise or artifact, and the list changes as ratings build up: strongly supported candidates become noteworthy, rejected ones leave the queue, and new survey runs add more. Five additional analyses go further, from a 25-year comparison with 2MASS, WISE and NEOWISE to spectra of interstellar comet 3I/ATLAS. Results are always called candidates, and missing data is shown as missing.
