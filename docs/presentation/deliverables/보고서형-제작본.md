## 편집 방향과 확인 결과

- 1920×1080 7장. 밝은 배경·네이비 계층 제목·얇은 구분선으로 통일했다. 기존 포스터형 문구를 줄이고 목적·방법·근거·한계를 독립적으로 읽을 수 있게 썼다.
- 아키텍처는 사용자가 제공한 계층형 도식을 참고했다. 입력 / 서버 API / 브라우저 분석 / 외부 데이터 / 저장소 / 출력 / 접근·보관·배포를 구분했다. 예시 이미지의 AI 에이전트·LLM·RAG 구조를 HEIMDALLR의 실제 구조라고 옮기지 않았다.
- 모든 텍스트·표·도식·미디어 프레임은 편집 가능하다. 글자 겹침·프레임 초과·컨테이너 초과 검사 통과. 각 장의 이미지를 확인했고, 수정한 장은 다시 확인했다.
- 사진·GIF는 요청에 따라 빈 교체 영역으로 남겼다. 안쪽 설명은 교체할 때 제거할 제작 지시이며, 바깥쪽 Figure 캡션은 독자를 위한 설명이다.
- 미확인 41개를 발견으로 쓰지 않았다. 포화된 중심과 고리 상대 밝기, 모델과 관측, 소리 변환과 녹음, 논문값과 도구 측정값을 구분했다.

### 1. REPORT / 01 / HEIMDALLR — project overview

Figma node: `3:460`

HEIMDALLR — project overview

An open web application for inspecting SPHEREx images and reviewing moving-object candidates. This report describes the method, implementation, evidence and limits.

SOURCE  docs/presentation/01-intro-team.md

Purpose and contribution

HEIMDALLR turns a position in the sky into a set of time-separated SPHEREx DR1 views. Users can inspect Blink, Difference and Stack views, open five additional analyses, and submit an anonymous judgment. The project supports candidate review; it does not claim a Planet X discovery or automated classification accuracy.

How the system combines machine and human work

1. Suggest locations

A SPHEREx × 2MASS survey compares positions over ~25 years. Gaia helps separate known movers and chance pairs.

2. Inspect the evidence

A reviewer checks aligned images, wavelengths, quality flags and supporting analyses before judging the candidate.

3. Accumulate reviews

Moving / Not moving / Noise or artifact ratings affect candidate status. Agreement is not scientific confirmation.

Users, team and implementation

For students, astronomy enthusiasts, citizen scientists and researchers.
Team: rreenactt · ansirh · tnsgud9. Public access, no sign-in; MIT licensed.
The app is built with Next.js, TypeScript, Aladin Lite and public astronomy archives.

AI tools assisted code and documentation. The team directs the work, reviews outputs and makes the project decisions. The repository includes an AI-use record.

### 2. REPORT / 02 / The problem, comparison rules and first survey

Figma node: `3:495`

The problem, comparison rules and first survey

A visual change can come from motion, wavelength, alignment, background or detector artifacts. The comparison must control these effects before a reviewer interprets it.

SOURCE  docs/presentation/02-problem-solution.md

Scientific risk and implemented rule

Risk

Implemented rule

Wavelength changes

Use the same detector; match the target-pixel wavelength within ±0.5 bandwidth.

Target recentering

Use one fixed 3′ × 3′ sky grid. Propagate Gaia positions to each visit epoch.

Short time baseline

Use ~25 years of 2MASS → SPHEREx positions when recent visits are insufficient.

Artifacts / background

Subtract the zodiacal model; inspect flags, PSF shape and repeatability. Keep useful OUTLIER signal.

Insufficient observations

0 visits: no observations. 1 visit: additional analysis needed. 2+: comparable visits.

Challenge coverage

Public web access, SPHEREx images, RA/Dec input and animated image comparison are implemented. The five required test targets are documented on page 7; their results still require human review.

First survey: 75,756 sky positions

SPHEREx (2025–26) was paired with 2MASS (~2000). The first run produced 5,384 source pairs. Gaia was checked at both ends of each pair.

Known-mover speeds differ from Gaia by a median 4.3%. A control set recovered 8 of 12 known high-proper-motion stars, with 1–8% speed differences and no false unidentified cases in that control set.

Four control targets were missed; the causes remain unresolved. The 41 unidentified pairs have not been confirmed by people, and some may be Gaia sources without proper-motion values.

These are survey counts and validation observations, not a discovery claim or a classification-accuracy estimate.

### 4. REPORT / 04 / Image comparison: Blink and Sky Time Machine

Image comparison: Blink and Sky Time Machine

01  Blink / Difference / Stack

Purpose: inspect a sky position across SPHEREx visits.
All frames use a fixed sky grid, matched wavelengths and a
shared display scale so display choices do not imitate change.

M02 / MATCHED SPHEREX VISITS

SCREENSHOT / GIF

Insert a Blink GIF or a strip of real visits with a wavelength/epoch key.

REPLACE WITH ACTUAL APP OR OBSERVATION CAPTURE

Figure 2. Matched SPHEREx visits share a fixed sky region. Observing date, detector and wavelength identify the frames being compared.

METHOD AND COMPARISON CONTROLS

Group visits at gaps >20 days; use up to 3 matched exposures per visit.
Read 48×48-pixel cutouts, subtract the zodiacal model and reproject
to a north-up 3′ × 3′ grid. Combine each visit by its median.
Gaia positions follow each epoch; masks and source links remain visible.

Interpretation limit

Difference residuals can also reflect PSF, alignment or wavelength differences. A blink is a review cue.

02  Sky Time Machine

Purpose: compare real epochs from 2MASS, WISE, NEOWISE
and SPHEREx. A ~25-year baseline can reveal motion that is
smaller than a SPHEREx pixel over recent visits.

M03 / HISTORICAL IMAGE COMPARISON

SCREENSHOT / GIF

Insert real common-grid 2MASS / WISE / SPHEREx frames.

REPLACE WITH ACTUAL APP OR OBSERVATION CAPTURE

Figure 3. Historical positions use actual observation epochs on one sky grid. Tool-computed coadds are labelled; brightness is not compared across missions.

METHOD AND MEASUREMENT

Use archive observation dates and image WCS, not release dates.
Reproject to a 256×256 north-up grid; default field 8′.
User-marked positions give motion in arcseconds per year.
Missing pixels are hatched; differently sized PSFs are disclosed.

Barnard's Star: 10.39″/yr

247.4″ over 23.81 years agrees with Gaia DR3. SPHEREx-only inter-visit position noise is ~9″.

CHECKS AND VALIDATION

Inspect flags, aperture S/N, PSF size/elongation, repeatability,
wavelength agreement and bright Gaia neighbors. Unchecked items
stay “Not checked”. Flag decompression matched all 5,112 IRSA
reference pixels. Unknown flag bits remain explicitly unknown.

MODEL, EVIDENCE AND LIMITS

Use linear motion; derive distance from parallax. Missing radial

Five required test targets

Target

Evidence and interpretation

Barnard's Star

247.4″ over 23.81 years = 10.39″/yr in Sky Time Machine; consistent with Gaia DR3.

Epsilon Indi B

Seen in all 6 exposures (S/N 97–102), within 1.1″ of the epoch-propagated predicted position.

WISE 0855−0714

Weak D6 signal (S/N 3.6–5.4) blends with a Gaia star 7.3″ away. Consistent, but not confirmed.

RW Aurigae

Core saturated. Matched relative annular change −0.024 ± 0.027 mag (23 pairs): no change found.

R Draconis

Core saturated. Relative annular dimming +0.62 ± 0.10 mag (4 pairs); not total-source photometry.

The saturated-core results and the annular measurements describe different quantities.
A faint signal or agreement with a prediction is not a confirmed object or a discovery.

Limits and next steps

Recent SPHEREx visits have limited motion sensitivity; parallax can move a source outside the 3′ field.
Uncached IRSA access may be slow or fail. Confirm R2 coverage and the current sky-backdrop source.
Next: review the 41 candidates, investigate missed controls, and add known-asteroid overlays.

Using the tool

1. Explore or search by RA/Dec.
2. Open a candidate or test target.
3. Compare visits and run extra analyses.
4. Rate Moving / Not moving / Noise.
5. Revise your vote after more analysis.
6. Share the coordinate URL.
