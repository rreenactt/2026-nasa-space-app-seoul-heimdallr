## 7장 구성과 시각 설계

1. **소개·팀** — 어두운 배경. 왼쪽에 HEIMDALLR과 공개 도구의 한 문장 설명, 오른쪽에는 기계의 후보 추천과 사람의 평가 순환 도식. 아래에는 세 팀원의 GitHub 아이디와 AI 사용 공개. 확인되지 않은 영문 이름과 담당 범위를 만들지 않는다.
2. **문제·해결·조사 결과** — 밝은 배경. 왼쪽에 비교를 어렵게 하는 세 조건, 오른쪽에 75,756곳 → 5,384짝 → 분류별 개수. 아래에 비교 원칙과 대조군 결과. 41개를 발견으로 표현하지 않는다.
3. **아키텍처** — 밝은 배경에 어두운 서버 영역. 데이터 원천 → TypeScript API → 브라우저를 가로로 연결하고 아래에 Neon·R2·조사 파이프라인을 배치한다. API·DB·사용자·저장 정책을 함께 제시한다.
4. **Blink·Sky Time Machine** — 어두운 배경. 위쪽에 블링크의 고정 격자·파장 조건과 세 보기, 아래에는 미션별 시간축과 Barnard's Star의 실제 측정값. 짧은 기준선의 잡음 한계와 미션 간 밝기 비교 금지를 명시한다.
5. **Fake Planet Lab·Neighborhood in Motion** — 밝은 배경. 왼쪽은 결함 점검과 상대 밝기 비교, 오른쪽은 근접 천체의 3D 모델과 관측 대조. 측정·모델·가정을 구분하고, 고리 밝기를 전체 밝기로 주장하지 않는다.
6. **Sky Sonata·Comet Breath** — 어두운 배경. 소리 매핑 규칙과 접근성 수단을 왼쪽에, 혜성의 두 관측 기간·분자 밴드·OUTLIER 교훈을 오른쪽에 배치한다. 소리 변환, 기간 합성, 논문 방출률을 명확히 구분한다.
7. **사용법·검증·정리** — 밝은 배경 위에 큰 사용 흐름. 다섯 테스트 대상의 결과를 간단한 표로 제시하고, 아래에 서비스 링크·남은 한계·다음 단계를 둔다. 검증 표의 사람 검토 전 상태를 보존한다.

공통: Space Grotesk 제목, Inter 본문, IBM Plex Mono 표식. 흑록색·미색을 주색으로, 라임을 후보와 핵심 근거, 주황을 제한과 가정에 쓴다. 좌표 조준선과 두 시점의 표식을 반복 모티프로 사용한다. 관측 이미지나 제품 캡처를 합성하지 않는다. 도식은 도식으로 표시한다.

## 내용 검토에서 적용한 판단

- `02`·`04`의 블링크 시각 이동 설명과 status의 방문 간 위치 잡음 약 9″ 기록을 함께 고려했다. SPHEREx 단독으로 Barnard's Star의 고유운동을 정밀 검증했다고 주장하지 않는다. 정량 근거는 23.81년의 247.4″, 즉 10.39″/년으로 제시한다.
- 포화로 전체 밝기 측정이 불가능하다는 테스트 표와, Fake Planet Lab의 고리 상대 밝기 측정은 서로 다른 양이다. R Draconis의 +0.62 ± 0.10 mag는 고리의 상대 밝기 변화임을 함께 쓴다.
- 75,756곳·5,384짝·262/5,081/41은 원고의 첫 조사 결과다. 41개는 사람의 확인 전이며, 4.3%는 알려진 움직이는 별의 Gaia 고유운동 대비 차이 중앙값이다. 분류 정확도나 발견 확률이 아니다.
- R2의 8.9초 → 0.28초는 원고의 동일 요청 측정이며 일반 성능 보장이 아니다. 프로덕션 저장 상태는 확인되지 않았으므로 배포 완료라고 쓰지 않는다.
- 원고의 Comet Breath 수치와 문헌 식별자를 옮기되, 논문 방출률을 이 도구에서 직접 추정한 값처럼 표현하지 않는다.
- 실제 사이트, 외부 데이터, 청각 경험을 이번 제작에서 새로 검증한 것은 아니다. 모든 수치는 제공 원고와 레포 기록에서 가져왔다.

## 제출 전 사람 확인

- 다섯 테스트 대상 결과의 최종 검토. WISE 0855는 확인 아님, RW Aurigae·R Draconis는 중심 포화.
- 미확인 41개 후보의 상태와 조사 집계 시점.
- 프로덕션 R2 환경 변수 및 사전 저장 범위, 하늘 배경의 실제 출처(원고는 CDS 장애에 따른 2MASS 대체).
- 세 팀원의 영문 이름·담당 범위는 확정 전이므로 슬라이드에서는 GitHub 아이디만 사용.
- Sky Sonata의 실제 청취 확인. 자동 점검으로 접근성 전체를 검증했다고 주장하지 않음.
- 관련 제안 상태 결정의 팀 확인.

작업 종료 시 담당자의 `docs/memory/status/rreenactt.md` 갱신과 `docs/memory/ai-usage.md`에 “ChatGPT/Codex가 제공된 7개 원고를 기반으로 영문 제출 슬라이드와 내용 검토 자료 제작” 한 줄 추가를 제안한다. 이 파일들은 이번 작업에서 수정하지 않는다.
