# 균형형 제출 자료 — 세 번째 디자인

기존 우주 콘셉트 7장과 보고서형 7장 아래에 추가한 세 번째 7장이다. 사용자가 두 버전의 중간, 즉 디자인과 가독성을 함께 갖추고 한눈에 구조를 이해할 수 있는 자료를 요청해 제작했다.

- 위치: 열려 있는 Design 파일의 `HEIMDALLR / Hackathon presentation` 페이지. `BALANCED / 01`–`BALANCED / 07`, y=2882.
- 로컬 Figma Bridge `127.0.0.1:3077`만 사용했다. 기존 14개 프레임은 유지했다.
- 전 장에 같은 짙은 네이비·보랏빛 그라데이션 제목 영역과 밝은 본문 배경을 적용했다.
- 기능 도식 → 짧은 설명 → 검증 수치 → 해석 한계 순으로 읽히게 구성했다. 수치와 도식을 단독으로 보더라도 의미가 이어지도록 했다.
- 미디어 영역 8개에는 편집 가능한 방법 도식을 넣었다. 관측 이미지나 실제 앱 캡처가 아님을 표시했으며, 실제 사진·GIF로 교체할 수 있다. 합성 관측 자료를 만들지 않았다.
- 7장 모두 텍스트 겹침·프레임/컨테이너 초과 검사를 통과했다. 동일한 제목 배경 사용을 확인했고 각 장을 이미지로 확인했다.
