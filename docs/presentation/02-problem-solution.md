# 2쪽. 챌린지가 제시한 문제와 우리의 해결책

## 문제

### 배경

- SPHEREx는 약 6개월마다 하늘 전체를 102개 밴드(0.75–5 μm)로 관측한다. 10억 개가 넘는 천체의 이미지가 쌓이고 있지만, 한 사람이나 코드 하나로는 다 살펴볼 수 없다.
- 같은 하늘을 시간 차이를 두고 찍은 이미지를 번갈아 보면(블링크), 고정된 별은 그대로 있고 움직인 천체만 자리를 옮긴다. 명왕성도 1930년에 이 방법으로 발견됐다.
- 챌린지는 이 블링크를 SPHEREx 이미지로 누구나 할 수 있는 공개 웹 도구를 요구한다.

### 챌린지 요구사항 (Planet X and SPHEREx)

| 구분 | 요구사항 |
| --- | --- |
| 필수 | 공개 웹 도구 |
| 필수 | SPHEREx 이미지 표시 |
| 필수 | RA/Dec 좌표 입력 |
| 필수 | 이미지를 짧은 영상처럼 재생 |
| 필수 | 움직이는 천체를 쉽게 발견 |
| 필수 | 테스트 대상 5개로 검증 (Barnard's Star, Epsilon Indi B, WISE 0855, RW Aurigae, R Draconis) |
| 선택 | 새 데이터 릴리스 반영, 102개 밴드 활용, 시점별 더하기·빼기, 시야 크기 선택, Gaia·WISE 겹쳐 보기, URL로 좌표 조회, 메타데이터·오염 플래그 표시, 공개 도구 활용 |

### 실제로 만들면서 확인한 어려움

1. **SPHEREx는 한 이미지 안에서도 위치마다 파장이 다르다 (LVF, 선형 가변 필터).** 아무 노출이나 섞어 비교하면 파장 차이가 "밝기 변화"처럼 보인다.
2. **목표 천체를 매번 화면 중앙에 맞추면 움직임이 사라진다.**
3. **SPHEREx 방문 사이(약 6개월)에는 대부분의 별이 한 픽셀(6.2″)도 움직이지 않는다.** 방문 간 위치 잡음이 약 9″라서, 가장 빠른 별인 Barnard's Star(10.4″/년)도 SPHEREx끼리만으로는 잡음과 구분되지 않았다.
4. **검출기 결함도 움직이는 점처럼 보인다** (우주선 흔적, 포화, 유령상, 잔상).

## 우리의 해결책

### ① 누구나 쓰는 3D 하늘 → 클릭 → 블링크

- 전체 화면 하늘(Aladin Lite, 시야 120°–0.05°)을 끌고 확대하다가 한 지점을 클릭하거나 좌표를 입력하면 분석 패널이 열린다.
- 패널은 그 지점의 SPHEREx DR1 이미지를 방문마다 한 장씩 **Blink / Difference / Stack** 세 가지로 보여준다.
- 좌표와 시야가 URL(`/?ra=&dec=&fov=`)에 담겨 그대로 공유할 수 있다.

### ② 틀리지 않게 비교하는 규칙

| 어려움 | 해결 |
| --- | --- |
| 파장이 위치마다 다름 | 목표 픽셀의 파장을 노출마다 계산해 **같은 검출기, 대역폭 ±0.5배 안의 파장**끼리만 비교 |
| 중앙 정렬하면 움직임이 사라짐 | **입력 좌표 기준 고정 하늘 격자**(3′×3′)에 모든 프레임을 놓음 |
| 계절마다 배경 밝기가 다름 | 황도광 모델(ZODI)을 빼고, 모든 방문에 같은 화면 밝기 범위 적용 |
| 알려진 별과 새 것의 구분 | Gaia DR3 별을 각 방문 날짜 위치로 옮겨 겹쳐 그림 |
| 관측이 부족함 | 지어내지 않고 상태로 표시: 방문 2회 이상 `comparable`, 1회 `additional analysis needed`, 0회 `no observations` |

### ③ 블링크만으로 부족한 부분을 채우는 추가 분석 5개

| 분석 | 채우는 부분 |
| --- | --- |
| Sky Time Machine | 6개월이 너무 짧다 → 2MASS부터 25년 기준선으로 위치 비교 |
| Fake Planet Lab | 결함인지 판별, 같은 파장끼리 방문 간 밝기 비교 |
| Neighborhood in Motion | 하늘 위 몇 ″의 이동을 3D 공간의 실제 운동으로 연결 |
| Sky Sonata | 화면을 보기 어려운 사용자를 위한 소리 변환 (접근성) |
| Comet Breath | 102개 밴드로 성간 혜성 3I/ATLAS의 분자 방출 변화 보기 |

### ④ 기계가 후보를 찾는다: SPHEREx × 2MASS 조사

- SPHEREx 위치(2025–26)와 2MASS 위치(약 2000년)를 비교해, 25년 동안 자리를 옮긴 광원의 짝을 찾는다. 짝마다 Gaia DR3로 확인해 셋으로 나눈다.
- **첫 조사 결과 (2026-11-15):** 무작위 75,756곳을 조사해 짝 5,384개를 찾았다.

| 분류 | 개수 | 뜻 |
| --- | --- | --- |
| Known mover | 262 | Gaia 별 하나가 양 끝을 모두 설명. 잰 속도와 Gaia 값의 차이 중앙값 4.3%. 방법이 맞는지 보는 정답지 |
| Gaia static | 5,081 | 한쪽 끝에만 정지한 Gaia 별이 있는 우연 짝. 목록에 올리지 않고 개수만 센다 |
| Unidentified | 41 | Gaia로 설명되지 않음. **사람이 확인할 후보이며 발견이 아니다** |

- 대조군: 고유운동이 알려진 별 12개 중 8개를 다시 찾았고(속도 차이 1–8%), 거짓 미확인은 0개였다. 놓친 4개(1.4″/년 이상인 2개와 밝은 별 일부)의 원인은 아직 조사하지 못했다.

### ⑤ 사람이 확인한다: 익명 평가

- 3지선다 `Moving` / `Not moving` / `Noise or artifact`. 로그인 없이 익명으로 저장한다.
- 쏠림을 막기 위해 **내가 평가하기 전에는 다른 사람의 평가를 볼 수 없다.**
- 평가가 쌓이면 후보 상태가 정해진다: 5건 미만 평가 부족, 5건 이상이고 Moving 30% 이상이면 추천 유지, Moving 30% 미만이거나 잡음·결함 50% 이상이면 추천 제외, 10건 이상이고 Moving 70% 이상인 미확인 후보는 주목할 후보.

### 테스트 대상 5개 검증 결과 (초안, 사람 검토 전)

| 대상 | 결과 |
| --- | --- |
| Barnard's Star | 방문 3회. 블링크에서 북쪽으로 움직이고 Gaia 예측 위치와 겹침. Sky Time Machine으로 23.81년 동안 247.4″ = 10.39″/년, Gaia DR3와 일치 |
| Epsilon Indi B | 6개 노출 모두에서 검출(S/N 97–102). Gaia 예측 위치에서 1.1″ 안. 2016년 위치에는 아무것도 없음 |
| WISE 0855−0714 | 기본 검출기(1.45 μm)에서는 보이지 않음. 4.6 μm에서 예측 위치에 약한 신호(S/N 3.6–5.4)가 있지만 7.3″ 옆 Gaia 별과 겹쳐 "일치하지만 확인된 것은 아님"으로 표시 |
| RW Aurigae | 모든 노출에서 중심 픽셀이 포화. 밝기 변화를 주장하지 않음 |
| R Draconis | 2.2 μm에서 완전히 포화되어 밝기 측정 불가. 숫자 대신 포화 플래그를 보여줌 |

잘 되는 경우와 안 되는 경우를 모두 그대로 적었다.
