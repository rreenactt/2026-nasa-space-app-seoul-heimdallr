# 7쪽. 이용 방법과 정리

## 이용 방법

사이트: <https://2026-nasa-space-app-seoul-heimdallr.vercel.app/> (로그인 없음, PC 브라우저 기준)

### 1. 하늘 둘러보기

- 짧은 인트로 뒤(`Skip intro`로 건너뛸 수 있음) 하늘이 화면을 채운다.
- 끌어서 이동하고 휠로 확대한다. 커서 아래의 RA/Dec가 표시된다.
- 넓은 시야에서 빈 곳을 누르면 그 지점으로 날아간다.
- 오른쪽 도구 줄: `This view`(중심 좌표, 시야, 배경 출처, 링크 복사), `Show on sky`(테스트 대상, 별자리 선, 좌표 격자, 후보), 확대·축소, 전체 화면, Star guide(고유운동이 큰 별 안내).

### 2. 볼 곳 고르기

| 방법 | 설명 |
| --- | --- |
| **Review queue** (왼쪽 위, `Q`) | 움직임 후보(Unidentified, Known mover)와 테스트 대상 5개. 평가 수 상위 10곳은 `Most rated` 탭 |
| **Search** (오른쪽 위, `/`) | 테스트 대상 이름, 후보 이름, 2MASS 이름, 또는 좌표 (`269.4485 4.7394`, `17 57 48.5 +04 41 36`) |
| **하늘에서 직접** | 시야 5° 이하로 확대하면 커서가 컷아웃 크기의 사각 조준선이 된다. 클릭하거나 `Enter`(화면 가운데) |

- 일반 천체 이름 검색(SIMBAD)은 CDS 장애로 아직 지원하지 않는다.

### 3. 변화 보기

- 분석 패널이 열리면 그 지점의 SPHEREx DR1 이미지를 **Blink / Difference / Stack**으로 본다.
- 검출기(D1–D6)를 바꿔 다른 파장으로 본다.
- Gaia DR3 별의 그 날짜 위치, 품질 플래그, IRSA 원본 링크가 함께 나온다.
- 관측이 부족하면 그렇게 표시한다: 방문 1회는 `Additional analysis needed`, 0회는 `No observations`.

### 4. 평가하기

- `Moving` / `Not moving` / `Noise or artifact` 중 하나를 고른다.
- 평가하기 전에는 다른 사람의 평가가 보이지 않는다. 평가한 뒤에 평가 수와 비율이 보이고, 나중에 바꿀 수 있다.

### 5. 더 깊이 보기

- "Additional analyses"에서 `Run`을 누르면 자료를 받은 뒤 패널 왼쪽에 탭으로 열린다. 여러 개를 동시에 받을 수 있다.
- Sky Time Machine, Fake Planet Lab, Neighborhood in Motion, Sky Sonata, Comet Breath.
- 추가 분석을 본 뒤 평가를 바꿀 수 있다.

### 6. 공유하기

| 주소 | 열리는 것 |
| --- | --- |
| `/?ra=&dec=&fov=` | 그 지점의 분석 패널 |
| `/?view=ra,dec,fov` | 패널 없이 그 하늘 |

### 그 밖에

- **About · Method** (가운데 탭): SPHEREx와 Planet X가 무엇인지, 비교 방법과 한계, 데이터 출처를 쉬운 말로 설명한다.
- **Menu** (오른쪽 위): 키보드 단축키(`?`), 평가 방법, 테스트 대상, 데이터 출처, 언어(영어·한국어).
- **주요 단축키:** `+` `−` 확대·축소, 화살표 이동, `Q` 검토 목록, `N` `P` 다음·이전 곳, `Enter` 열기, `C` 후보 표시, `L` Show on sky, `/` 검색, `Esc` 닫기.

## 정리

### 만든 것

| 항목 | 내용 |
| --- | --- |
| 공개 웹 도구 | 로그인 없이 3D 하늘에서 한 지점을 골라 SPHEREx DR1 블링크·차분·합산을 본다 |
| 분석 도구 6개 | Blink, Sky Time Machine, Fake Planet Lab, Neighborhood in Motion, Sky Sonata, Comet Breath |
| 기계의 후보 | SPHEREx × 2MASS 조사로 75,756곳에서 Known mover 262개, Unidentified 41개 |
| 사람의 확인 | 익명 3지선다 평가, 평가가 쌓이면 후보 상태가 바뀜 |
| 검증 | 챌린지 테스트 대상 5개를 도구 자체의 분석 코드로 측정 (초안, 사람 검토 전) |

### 핵심 숫자

- Barnard's Star: 25년 비교로 **10.39″/년**, Gaia DR3와 일치
- 조사에서 다시 찾은 알려진 별 262개의 속도: Gaia 값과 **중앙값 4.3% 차이**
- 미확인 후보는 처음 1,766개였지만, Gaia 확인을 양 끝으로 넓히자 97.7%가 우연 짝으로 밝혀져 **41개**가 남았다

### 정직하게 만든 부분

1. 결과는 "감지"나 "발견"이 아니라 언제나 **후보**다.
2. 같은 검출기, 비슷한 파장끼리만 비교한다.
3. 고정 하늘 격자에서 비교한다.
4. 데이터를 지어내지 않는다. 관측이 부족하면 부족하다고 표시하고, 합성 자료는 합성이라고 표시한다.
5. 안 되는 경우도 그대로 보여준다 (WISE 0855는 확인 아님, RW Aurigae와 R Draconis는 포화).
6. 원본 FITS는 저장하지 않는다.

### 한계

- SPHEREx는 한 지점을 1년에 약 두 번 방문한다. 대부분의 별은 방문 사이에 한 픽셀(6.2″)보다 훨씬 적게 움직인다. 블링크는 판정이 아니라 "볼 곳"이고, 느린 움직임은 25년 비교가 맡는다.
- 아주 먼 태양계 천체는 지구의 운동 때문에 방문 사이에 수 분각을 옮겨 간다. 3′ 컷아웃보다 커서, 한 방문에는 보이고 다음 방문에는 없게 된다.
- 미확인 후보 41개는 아직 사람이 확인하지 않았다. 일부는 Gaia에 고유운동 값이 없는 별일 수 있다.
- 분석은 IRSA에 의존한다. IRSA가 느리거나 오류를 내면 미리 저장하지 않은 지점은 늦게 열리거나 실패 안내가 나온다.
- CDS 장애 동안 하늘 배경은 SPHEREx가 아니라 2MASS다. 분석은 영향을 받지 않는다.
- 시야 크기 선택, 알려진 소행성 겹쳐 보기는 아직 없다.

### 다음 단계

- SPHEREx 관측이 쌓일수록 방문 수가 늘어 비교가 강해진다.
- 알려진 소행성 겹쳐 보기 (JPL, SkyBoT).
- 미확인 후보 확인과, 대조군에서 놓친 빠른 별의 원인 조사.
- 조사 파이프라인의 예약 실행으로 후보를 계속 늘리기.
