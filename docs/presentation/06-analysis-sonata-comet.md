# 6쪽. 분석 도구 ⑤ Sky Sonata, ⑥ Comet Breath

## ⑤ Sky Sonata (들리는 하늘)

**무엇을 알려주나.** SPHEREx 영상 속 광원을 정해진 규칙에 따라 소리로 바꾼다. 같은 지점의 두 관측(A·B)을 같은 규칙으로 이어 들어, 자리를 옮기거나 밝기가 바뀐 광원을 귀로 비교한다.

**왜 필요한가.** 화면을 보기 어려운 사용자도 하늘 비교에 참여할 수 있다 (접근성).

### 소리 규칙 (고정, 화면에 공개)

| 영상에서 | 소리에서 |
| --- | --- |
| 가로 위치 | 좌우(스테레오 위치)와 재생 시점 (기본 6초에 왼쪽 → 오른쪽) |
| 세로 위치 | 음높이, 위가 높음 (기본 220–1760 Hz) |
| 밝기 | 음량 (로그 압축) |
| 포화된 광원 | 네모파 (밝기를 믿을 수 없음) |
| 자료 없음 | 낮은 이중 클릭 |

- **"우주에서 녹음한 소리"가 아니라 규칙을 공개한 변환**이라고 화면 맨 위에 적는다.
- 광원은 화면 대비와 무관하게 원본 픽셀에서 찾는다 (배경 대비 5σ 이상).

### A·B 비교

- **기본 A·B:** 블링크와 같은 계획에서 첫 방문과 마지막 방문의 **같은 파장** 노출을 고른다.
- 두 영상은 **같은 밝기 범위**를 공유한다. 각자 따로 정규화하지 않는다.
- 광원을 하늘 위치로 짝짓고(9.3″ 이내) 분류한다: `About the same` / `Brighter in B` · `Fainter in B` / `Only found in A` · `Only found in B` / `Saturated`.
- 광원마다 A 음 → 0.45초 뒤 B 음을 같은 음높이·같은 좌우로 낸다. 달라지는 것은 음량뿐이라 밝기 차이가 바로 들린다.
- 영상의 아무 곳이나 누르면 그 자리를 A로, 이어서 B로 들려준다.

### 접근성

- 키보드만으로 조작한다: 방향키로 지점 이동, `Enter` 다시 듣기, `N` · `P` 다음·이전 광원.
- 모든 소리를 문장(`aria-live`)과 광원 표로도 제공한다.
- 낮은 기본 음량, 항상 보이는 `Stop all sound`, 모노 모드.
- 연습용 예제 3개는 `Synthetic practice — not observation data`로 구분한다.

**화면.** Listen / Practice / Rules & sources 탭.

### 검증

- 규칙 시험: 좌우만 다른 두 점은 좌우만, 위아래만 다른 두 점은 음높이만(1430 / 271 Hz), 밝기만 다른 두 점은 음량만(0.07 / 0.29) 달라진다. 같은 영상을 A·B로 넣으면 소리 이벤트가 완전히 같다.
- RW Aurigae 시야(D3)에서 기본 A·B가 같은 파장(약 2.152 μm)의 2025-09-18, 2026-02-21 노출로 잡혔다. 광원 짝 14개: 같음 9, A에만 1, B에만 1, 포화 3.
- **소리 자체는 사람이 직접 들어 확인해야 한다.** 자동으로 확인한 것은 재생 예약, 안내 문장, 화면 표시까지다.

### 한계

- 재생할 광원 수에 상한이 있다. "소리 없음 ≠ 빈 하늘"이라고 적는다.
- "다름"은 PSF 차이나 허용치 안의 파장 차이로도 나올 수 있다. 검출이 아니라 볼 곳의 목록이다.

## ⑥ Comet Breath (성간 혜성의 숨결)

**무엇을 알려주나.** 성간 혜성 **3I/ATLAS**를 SPHEREx가 근일점 전(2025-08-01–15)과 후(2025-12-08–14)에 찍은 영상과 스펙트럼을 보여주고, 물·CO₂·CO 방출이 두 시기 사이에 어떻게 달라졌는지 논문의 방출률과 함께 비교한다.

**왜 필요한가.** SPHEREx의 102개 밴드가 분자 밴드(CO₂ 4.26 μm, CO 4.65 μm 등)를 직접 잡는다는 것을 보여준다. 고정 좌표로는 찾을 수 없는 이동 천체를 관측 시점별 예측 좌표로 다루는 예시이기도 하다.

**적용 대상.** 3I/ATLAS 전용이다. 패널에서 고른 지점과 무관하게 전용 데이터셋을 연다.

### 어떻게 만드나

- **관측 목록:** IRSA의 3I/ATLAS 전용 목록(259행)에서 노출과 시점별 혜성 예측 좌표를 받는다.
- **픽셀:** 같은 노출을 DR1에서 확인된 것만 쓴다. AWS 공개 버킷에서 바이트 범위로 읽는다.
- **측광:** 혜성 예측 좌표에 반경 2픽셀 조리개와 배경 고리. 혜성 픽셀의 파장을 계산해 그 파장에 점을 놓는다.
- **스펙트럼:** 여러 날짜의 점을 모은 "기간 합성 스펙트럼"이다. 보간하지 않는다.
- **방출률:** 직접 계산하지 않고 **논문값을 인용한다** (Lisse et al. 2025, 2026: arXiv:2512.07318, arXiv:2601.06759).
- 관측이 없는 "근일점 부근" 기간은 만들지 않는다.

**화면.** Images / Spectrum / Production rates / Evidence 탭. 기간(8월·12월), 검출기, 날짜 슬라이더를 탭끼리 공유한다.

### 만들면서 배운 것: OUTLIER 플래그

SPHEREx 파이프라인은 혜성 코마 중심을 `OUTLIER`로 표시한다. 처음에 이를 가렸더니 CO₂ 플럭스를 약 93% 낮게 쟀다. 그래서 측정 영역에서는 가리지 않고 배경 고리에서만 가린다. 이 규칙은 블링크와 Fake Planet Lab에도 똑같이 적용했다.

### 검증

- 8월 관측 12개 중 9개, 12월 24개 모두 품질 점검 통과.
- (검증 성과에서 뺌) 12월 4.21 μm 구간 값은 CO₂ 밴드(4.23–4.27 μm) 밖이고, 앱 측광은 분자 방출을 검증하지 않는다. 방출률은 논문 인용값이며 8월 CO는 잠정 검출이다.

### 한계

- 측광값은 거리 보정을 하지 않아 논문 그림과 절대값을 바로 비교할 수 없다.
- 분자 밴드 세기를 직접 계산하지 않는다.
- 지금은 추가 분석 목록에서 `3I/ATLAS only`로 연다. 하늘의 전용 핀에서 여는 방식은 아직 정하지 않았다.
