## ① Blink (기본 분석: Blink · Difference · Stack)

**무엇을 알려주나.** 고른 지점을 SPHEREx가 찍은 방문(약 6개월 간격)마다 한 장씩 만들어 세 가지로 보여준다.

| 보기 | 내용 |
| --- | --- |
| Blink | 방문을 시간순으로 번갈아 보인다. 자리를 옮긴 점이 깜빡인다 |
| Difference | 지금 방문 − 첫 방문. 고정된 별은 지워지고 변화는 파랑·주황 쌍으로 남는다 |
| Stack | 모든 방문의 평균. 어두운 고정 천체가 잘 보인다 |

**어떻게 만드나.**

1. **검색:** IRSA SIA2로 그 지점을 덮는 DR1 노출을 모두 받는다. 개수 상한으로 자르지 않는다.
2. **방문 묶기:** 시간순으로 정렬해 20일 넘게 떨어지면 새 방문으로 나눈다.
3. **검출기:** 노출이 가장 많은 검출기를 자동으로 고른다. 사용자가 D1–D6으로 바꿀 수 있다.
4. **파장 맞추기:** 목표 픽셀의 파장을 노출마다 계산해, 기준 파장에서 대역폭의 ±0.5배 안인 노출만 쓴다. 방문마다 최대 3장.
5. **픽셀 읽기:** AWS 공개 버킷에서 목표 주변 48×48 픽셀만 읽고, 읽은 파일로 파장을 다시 확인한다.
6. **배경과 불량 픽셀:** IMAGE − ZODI(황도광 모델)로 계절 차이를 없앤다. 불량 픽셀 비트만 가린다.
7. **고정 격자:** 입력 좌표 중심 3′×3′, 96×96 픽셀, 북쪽 위 격자에 재투영하고 방문별로 중앙값으로 합친다.
8. **Gaia 겹치기:** Gaia DR3 별(G < 16)을 각 방문 날짜 위치로 옮겨 원으로 그린다.

**지키는 원칙.**

- 모든 방문에 같은 화면 밝기 범위를 쓴다. 대비 조정이 "변화"처럼 보이지 않게 하기 위해서다.
- `OUTLIER` 플래그는 가리지 않는다. SPHEREx 파이프라인이 움직이는 천체도 OUTLIER로 표시하기 때문이다.
- 빠진 노출은 이유와 함께 표에 남긴다 (검출기 밖, 파장 밖, 3장 초과).

**함께 보이는 것.** 실제 관측 시각 간격대로 놓인 타임라인, 노출별 측정 파장과 품질 플래그, IRSA 원본 링크. 키보드 `Space` 재생·정지, `←` `→` 방문 이동, `1`–`3` 보기 전환.

**검증.** Barnard's Star: 방문 3회(노출 4장). 블링크에서 별이 북쪽으로 움직이고 Gaia 예측 위치와 겹친다. 파장 추정과 파일에서 읽은 실제 파장의 차이는 약 0.001 μm.

**한계.** Difference에 남는 무늬는 이동뿐 아니라 PSF, 정렬 오차, 허용치 안의 파장 차이로도 생긴다. 판정이 아니라 "자세히 볼 곳"이다. 알려진 소행성 겹쳐 보기는 아직 없다.

## ② Sky Time Machine (25년 하늘 비교)

**무엇을 알려주나.** 같은 하늘 조각을 실제 관측 순서대로 넘겨 본다.

> 2MASS (약 2000년) → WISE (2010) → NEOWISE (2014–2024) → SPHEREx (2025–)

**왜 필요한가.** SPHEREx 방문 사이 6개월로는 느린 천체가 거의 움직이지 않는다. 25년이면 같은 천체가 수십–수백 ″ 움직여 눈에 보인다. SPHEREx 방문이 1회뿐인 지점에서도 쓸 수 있다.

**어떻게 만드나.**

1. 미션마다 IRSA SIA2로 실제 관측 시각을 찾는다 (공개일이 아니라 관측 시각).
2. 노출을 20일 간격 기준으로 관측 통과로 묶는다.
3. 각 영상의 WCS를 읽어 공통 격자(256×256, 북쪽 위)에 재투영한다. 기본 시야 8′.
4. 사용자가 시점마다 별 위치를 찍으면 이동량(″/년)을 잰다. Gaia 예상 경로를 함께 그린다.

**화면.** Timeline / Compare two dates / Motion / Evidence 탭.

**지키는 원칙.**

- **위치만 비교하고 밝기와 차분은 비교하지 않는다.** 미션마다 파장이 달라서, 다른 탐사 이미지끼리 빼면 고정된 별도 지워지지 않는다.
- WISE·NEOWISE 시점은 이 도구가 단일 노출을 통과마다 최대 5장 받아 중앙값으로 합친 것이다. 공식 시간분해 합성 영상이 이미지로 공개되어 있지 않기 때문이며, 화면에 "이 도구에서 계산한 합성"이라고 표시한다.
- 자료가 없는 픽셀은 검은 하늘로 칠하지 않고 빗금으로 보인다.
- 미션마다 픽셀 크기가 다르다 (2MASS 약 2″, WISE 2.75″, SPHEREx 6.15″). 별 모양 차이를 움직임으로 보지 않도록 안내한다.

**검증.**

- Barnard's Star: 사용자 표시로 잰 이동 247.4″ / 23.81년 = **10.39″/년**, Gaia DR3와 일치.
- NEOWISE 2014.22 → 2024.21 사이 밝기 중심 이동 105″ / 10년 = 10.5″/년 (Gaia 10.36″/년).
- 기준 별 위치 오프셋은 미션별로 0.06–0.48″ (격자 1.88″).

**한계.** 밝은 별은 2MASS·WISE에서 포화되어 밝기 중심이 몇 ″ 어긋날 수 있다. 자료를 받는 데 시간이 걸린다 (Barnard's Star 8′ 시야 27시점에서 약 48초, 한국 PC 측정).
