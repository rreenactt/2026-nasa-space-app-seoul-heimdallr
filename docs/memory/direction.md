# 방향성

> 팀 합의로만 바꾼다. 바꾸면 [`decisions.md`](../decisions.md)에 기록한다.
> 최종 갱신: 2026-11-14

## 비전

누구나 SPHEREx의 실제 관측으로 하늘의 변화를 직접 보고, 움직이는 천체 후보를 함께 찾고 검증하는 공개 웹 도구를 만든다.

**기계가 후보를 찾고, 사람이 확인한다.** 사전 분석이 움직임 후보를 추천하고, 사용자가 블링크로 보고 평가하며, 평가가 쌓이면 후보가 걸러진다.

## 대상 사용자

1. 천문에 관심 있는 일반인·학생
2. 시민과학 참여자
3. 빠르게 확인하고 싶은 연구자

## 범위

| 안 | 밖 |
| --- | --- |
| 좌표 입력·3D 하늘 클릭으로 SPHEREx 블링크·차분·합산 보기 | 전천 자동 분석 |
| 테스트 대상 5개 검증 | 정량 광도 측정을 조건 없이 제공 |
| 기능 A: 사전 분석 움직임 후보 추천 (분석하며 점점 늘림) | Planet X 발견 주장 |
| 기능 B: 사용자 평가 (3지선다, 평가 전 집계 숨김) | 로그인, 개인정보 수집 |
| 추가 분석 5개 (`docs/analyses/`) | 원본 FITS 저장·배포 |
| 영어 제출물 (요약, 7장 데모, 상세 설명) | 모바일·좁은 화면 대응 (PC 브라우저만) |

## 하지 않는 것

- 결과를 "발견"이나 "감지"로 표현하지 않는다. 항상 "후보"다.
- 관측이 부족할 때 데이터를 지어내지 않는다.
- 사람의 평가를 과학적 확인처럼 표시하지 않는다. "합의도"로 표시한다.

## 심사 기준별 전략

| 기준 | 보여줄 것 |
| --- | --- |
| Impact | 누구나 클릭 몇 번으로 발견 과정에 참여, 평가가 쌓일수록 후보가 걸러지는 구조, 접근성(Sky Sonata) |
| Creativity | 1인칭 3D 하늘 탐색, 기계 후보와 사람 평가를 잇는 순환, 25년 비교(Sky Time Machine) |
| Validity | 테스트 대상에서 Gaia 예측과 관측 비교, 오탐 판별(Fake Planet Lab), 안 되는 경우도 솔직히 기록 |
| Relevance | 챌린지 필수 6개 전부, 선택 8개 모두 대응 |
| Presentation | 7장 슬라이드, 블링크 GIF, 3D 이동 연출 |

심사위원: 한국천문연구원, AWS 우주위성사업부, 서울대 데이터사이언스대학원, 연세대 컴퓨터과학과. 용어 정확성과 데이터 처리의 타당성 설명이 특히 중요하다.

## 차별점

공개된 다른 팀 레포 대부분은 2D 블링크 뷰어나 자동 탐지에서 끝난다. 우리는 3D 탐색, 기계 후보, 사람 검증을 하나의 흐름으로 묶는다.
