# 용어집

> 코드, 화면 문구, 문서에서 같은 뜻에는 같은 말을 쓴다. 화면 문구(영어)는 오른쪽 열을 따른다.

| 용어 | 뜻 | 화면 문구 (영어) |
| --- | --- | --- |
| 방문 | SPHEREx가 같은 하늘을 다시 찍은 한 차례 (약 6개월 간격). 한 방문 안에 여러 프레임이 있을 수 있다 | visit |
| 관측 시점 | 프레임이나 방문의 관측 날짜·시각 (UTC) | observed at / epoch |
| 블링크 | 방문별 이미지를 번갈아 재생해 움직임을 보는 방식 | Blink |
| 차분 | 나중 방문 이미지에서 첫 방문 이미지를 뺀 것 | Difference |
| 합산 | 여러 방문 이미지를 더한 것 | Stack |
| LVF | Linear Variable Filter. 한 이미지 안에서도 위치마다 파장이 다른 SPHEREx의 필터 | - |
| 검출기 | SPHEREx의 6개 검출기 배열 D1–D6, 파장 구간이 다름 | Detector D1–D6 |
| 컷아웃 | 큰 원본 이미지에서 잘라낸 작은 영역 | cutout |
| 고정 하늘 격자 | 입력 좌표를 기준으로 고정한 공통 좌표 격자. 모든 방문을 여기에 정렬한다 | - |
| 시야 | 컷아웃의 크기 (기본 3′ × 3′) | Field of view |
| 후보 | 움직임이 있을 수 있는 천체. 확정이 아니다 | Motion candidate |
| 알려진 소행성 | JPL·MPC 목록과 일치하는 이동 천체 | Known asteroid |
| 미확인 후보 | 어떤 목록과도 일치하지 않는 후보 | Unidentified |
| 주목할 후보 | 평가 합의도가 높은 미확인 후보 | Notable candidate |
| 추천 제외 | 평가가 낮아 추천 마커에서 뺀 상태. 삭제가 아니다 | - |
| 평가 | 사용자의 3지선다 판정 | Moving / Not moving / Noise / artifact |
| 합의도 | 평가 중 "움직인다" 비율. 과학적 확인이 아니다 | agreement |
| 기능 A | 사전 분석 움직임 후보 추천 | - |
| 기능 B | 사용자 평가 | - |
| 기본 분석 | 좌표마다 항상 실행하는 처리 (블링크·차분·합산, 겹쳐 보기) | Basic view |
| 추가 분석 | 사용자가 골라서 실행하는 분석 (`docs/analyses/`) | Additional analysis |
| 사전 저장 | 후보·테스트 대상 좌표를 미리 처리해 저장해 둔 것 | - |
| 실시간 + 캐시 | 임의 좌표를 요청 시 처리하고 일정 기간 보관하는 것 | - |
| 릴리스 | SPHEREx 데이터 공개 단위 (QR2, QR3, DR1). DR1 우선 | release |
| 고유운동 | 별이 하늘에서 1년에 움직이는 각도 (″/yr) | proper motion |
| 시차 | 지구 공전 때문에 가까운 천체가 앞뒤로 흔들려 보이는 것 | parallax |
| 테스트 대상 | 챌린지가 지정한 5개 천체 | Test targets |
