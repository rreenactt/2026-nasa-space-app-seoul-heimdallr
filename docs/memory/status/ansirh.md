## 완료

- 실제 움직임 후보 연결 (결정 #51): 최신 조사의 Known mover(정답지)·Unidentified(판단 대상)를 검토 목록·하늘·This view·분석 패널에 표시. Gaia 정지 우연 쌍은 개수만. 후보 이름은 SPHEREx 위치의 J 이름
- 하늘 위 후보 표시 개편 (결정 #52·#53): 육각형 밀도 칸 제거, 80°보다 넓으면 표시 없음, 80–5° 하늘 고정 격자 묶음 원, 5° 미만 개별 기호. 0.25초 나타남·사라짐, 최대 확대에서 기호 확대와 이름표
- 이름 검색 (결정 #54): 후보 이름(`J082927.2+550714`)과 2MASS 이름(`J08292680+5507243`)을 매번 DB에 직접 묻는 `/api/candidates/lookup`(캐시 없음)으로 찾음. 후보 추가·삭제를 바로 반영하고 열린 탭 목록도 맞춤. 목록 캐시는 1분
- 검토 목록 선택과 열기 분리 (결정 #49): 행 클릭·`N` `P`는 선택하고 날아가기만, 하늘에 링과 ID·RA/Dec 이름표. `Enter`·Open blink·다시 클릭으로 연다. 목록을 접으면 선택 해제. 선택이 없으면 `Enter`는 화면 가운데 분석
- 화면 중심 십자선 (결정 #50): 5° 이하·액자 없음에서 가운데가 빈 십자선과 RA/Dec, `Enter` 키 표시
- Figma 정리: 현재 시안을 줄별(Explore, Review screens, Pages)로 배치하고 예전 시안은 "Sky screen · Archive" 페이지로 옮김. "nothing selected", "aiming (view center)" 프레임 추가

## 막힘

- `/api/ratings`는 빌드할 때 `DATABASE_URL`이 필요하다. 로컬은 `.env`로 해결. Vercel에 이 변수가 있는지 이순형 확인 필요
- CDS 장애로 하늘 배경은 SPHEREx가 아닌 2MASS 임시 배경이다 ([결정 #25](../../decisions.md))
- 타일 프록시 적용은 배포 담당(이순형) 확인 필요 (`PLAN.md` 14장)
- 팀 결정 대기: 컷아웃 크기(#19, 챌린지 선택 4 "시야 크기 선택"과 직결), 추가 분석 결과 요약 줄, 3I/ATLAS 진입 위치, 이름 검색 대체(J 이름은 #54로 해결, 일반 천체 이름은 여전히 SIMBAD 필요)
