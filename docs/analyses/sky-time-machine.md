# Sky Time Machine (25년 하늘 비교기)

| 항목 | 내용 |
| --- | --- |
| ID | `sky-time-machine` |
| 상태 | 확정 · **1차 구현됨** (독립 팝업, 분석 패널 통합 전) |
| 담당 | 김재현 (`rreenactt`) |
| 출력 종류 | view, overlay |
| 최소 SPHEREx 방문 횟수 | 1 (과거 미션 데이터로 비교) |
| 적용 대상 | 모든 좌표 (2MASS·WISE 관측이 있는 영역) |
| 화면 배치 | 추가 분석 목록 → 실행 시 뷰어에 연도 슬라이더 모드 추가 |
| 난이도 | 중 (하에 가까움) |
| 예상 소요 시간 | 미정 |

## 1. 무엇을 알려주나

2MASS(약 2000년)부터 AllWISE·NEOWISE·SPHEREx까지 약 25년 동안의 적외선 하늘을 한 슬라이더로 넘겨 보며, 긴 기간 동안 누적된 이동을 궤적선으로 보여준다.

## 2. 왜 필요한가

SPHEREx는 아직 한 영역당 2~3회만 관측해 기간이 짧고 화소(6.2″)도 크다. 느린 천체는 SPHEREx만으로는 거의 안 움직이지만, 25년 기준선에서는 뚜렷한 궤적이 된다. 사용자가 "정말 움직였나"를 판단하는 데 직접 도움이 되고, 발표 효과도 크다.

## 3. 입력 데이터

- 기본 분석 결과: 입력 좌표, 시야, SPHEREx 방문별 컷아웃
- 외부 데이터: 2MASS, AllWISE·NEOWISE (IRSA, unWISE 시간분해 영상), Gaia DR3
- WiseView는 열람용 웹 도구이므로 자동 처리에는 원본 데이터를 쓴다.

## 4. 방법

1. 같은 좌표·시야로 미션별 컷아웃을 받는다.
2. 미션마다 다른 해상도·파장을 맞춰 같은 하늘 격자에 정렬한다.
3. 연도 타임라인을 만들고, 실제 관측이 있는 시점으로 슬라이더를 맞춘다.
4. 긴 기준선 동안의 누적 이동을 궤적선으로 표시한다.
5. 임의의 두 시점을 골라 블링크 비교할 수 있게 한다.

## 5. 출력

- **한 줄 요약 예시:** "2000–2026 · 4개 미션 · 누적 이동 궤적 표시"
- **view:** 뷰어에 연도 슬라이더 모드 추가, 미션 이름과 연도 표시
- **overlay:** 25년 누적 이동 궤적선
- **결과 없음:** "과거 미션 관측 없음" 또는 "25년 동안 뚜렷한 이동 없음"

## 6. 실행 조건과 한계

- 미션마다 화소 크기가 달라 별의 퍼짐이 다르다. 이를 움직임으로 오해하지 않도록 안내한다.
- 미션마다 파장이 달라 밝기 비교와 차분은 하지 않고 위치(움직임)만 비교한다. SPHEREx는 비교할 미션과 파장이 가까운 채널을 쓴다 ([기획서 4장](../PLAN.md#다른-탐사와-비교할-때)).

## 7. 검증

Barnard's Star처럼 고유운동이 큰 별에서 25년 궤적이 Gaia 예측과 일치하는지 확인한다.

## 8. 참고 자료

- 출처: 팀 아이디어 쇼케이스 문서 (Planet X and SPHEREx 해커톤 프로젝트 아이디어 13선)
- [WiseView](http://byw.tools/wiseview)

## 9. 구현 기록 (2026-11-14)

- **위치:** 홈의 `Sky Time Machine` 팝업 (`app/_components/sky-time-machine/`). 탭: 타임라인·재생 / 두 시점 비교 / 이동 표시 / 근거 확인.
- **검색:** 미션마다 IRSA SIA2 한 번(`twomass_allsky`, `wise_allsky`·`wise_3bandcryo`·`wise_2bandcryo`, `neowiser`, `spherex_dr1`). 시각은 공개일이 아니라 SIA2의 `t_min`·`t_max`(실제 관측 시각)를 쓴다. 노출을 20일 간격 기준으로 관측 통과(방문)로 묶는다.
- **WISE·NEOWISE 시점 (결정 #26):** 공식 unWISE 시간분해 합성 영상은 IRSA·AWS 공개 버킷·NERSC 공개 경로 어디에도 이미지로 공개되어 있지 않았다(카탈로그만 있음). 대신 IRSA WISE/NEOWISE L1b 단일 노출을 통과마다 최대 5장(통과 전체에 고르게) 받아, MAGZP 22.5로 맞추고 배경 중앙값을 뺀 뒤 픽셀별 중앙값으로 합친다. 화면·근거에 "이 도구에서 계산한 합성"으로 표시한다.
- **2MASS:** 같은 밤의 Atlas 타일 중 시야 중심에 가까운 것 최대 4장을 함께 쓴다. **SPHEREx:** 통과마다 노출 1장(가운데), 원본을 바이트 범위로 읽고 시야 중심 파장을 `WCS-WAVE`로 계산해 표시한다.
- **정렬:** TAN(SIN·SIP 포함) WCS를 직접 읽어 공통 격자(256×256, 북쪽 위·동쪽 왼쪽)에 쌍선형 재투영한다. 자료 없는 픽셀은 빗금으로 표시한다(검은 하늘로 칠하지 않음).
- **검증:** Barnard's Star 시야에서 Gaia DR3 기준 별을 각 시점으로 옮겨 비교하니 2MASS(2000.41) 0.06″/0.02″, WISE(2010.21) 0.11″/−0.20″, NEOWISE(2014.22·2024.21) 0.48″, SPHEREx(2025.64) 0.08″/−0.35″ 오프셋 (흩어짐 0.3–1.0″, 격자 1.88″). 사용자 표시로 잰 Barnard's Star 이동 247.4″ / 23.81년 = 10.39″/년, Gaia DR3와 일치.
- **이동 표시:** 사용자 표시 위치, 측정 위치(밝기 중심), Gaia 예상 위치·경로(2016.0 + 선형 고유운동, 시차 무시)를 구분해 그리고, 표시 위치끼리의 점선이 실제 경로가 아님을 적는다. Gaia 조회는 ESA Gaia Archive 우선(결정 #27).
- **남은 일:**
  - 화면 문구가 한국어다(`AGENTS.md` 작업 규칙은 영어).
  - SPHEREx 채널을 비교 미션 파장(2MASS 1.2·1.6·2.2 μm, WISE 3.4·4.6 μm)에 자동으로 맞추지 않는다. 지금은 검출기를 직접 고른다(기본 D4).
  - 공유 URL이 `/?stm=ra,dec,fov`로 결정 #21의 `/?ra=&dec=&fov=`와 다르다.
  - 사전 저장 계층 없이 매번 실시간으로 받는다. 시점당 수 초, IRSA 503(과부하)이 가끔 난다.
