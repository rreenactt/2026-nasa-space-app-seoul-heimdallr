# Comet Breath (성간 혜성의 숨결)

| 항목 | 내용 |
| --- | --- |
| ID | `comet-breath` |
| 상태 | 확정 · **화면 배치 논의 필요** |
| 담당 | |
| 출력 종류 | view, chart |
| 최소 SPHEREx 방문 횟수 | 해당 없음 (전용 데이터셋 사용) |
| 적용 대상 | **성간 혜성 3I/ATLAS만** |
| 화면 배치 | **특별 대상 페이지 권장** (하늘의 3I/ATLAS 핀에서 진입) |
| 난이도 | 중 |
| 예상 소요 시간 | 미정 |

## 1. 무엇을 알려주나

성간 혜성 3I/ATLAS의 SPHEREx 관측으로 물·CO₂·CO 방출이 관측 시기(근일점 전·부근·후)별로 어떻게 바뀌는지 보여준다.

## 2. 왜 필요한가

IRSA에 이미 정리되어 공개된 화제성 큰 전용 데이터셋이라 데이터 준비 시간이 짧다. "시간에 따른 변화"라는 챌린지 주제와 맞고, 102개 파장의 가치를 보여주기 좋다.

## 3. 입력 데이터

- IRSA SPHEREx 3I/ATLAS 전용 스펙트럼 이미지
- JPL Horizons (태양과의 거리, 관측 시각별 위치)

## 4. 방법

1. 3I/ATLAS 전용 영상을 로드하고 코마 영역 스펙트럼을 추출한다.
2. 물·CO₂·CO 분자 밴드 세기를 관측 시기별로 비교한다.
3. 태양과의 거리 변화와 연동한 그래프를 만든다.

## 5. 출력

- **view:** 혜성 이미지와 시기 탭 (근일점 전 / 부근 / 후)
- **chart:** 분자별 밴드 세기 막대, 태양 거리 대비 그래프

## 6. 실행 조건과 한계

- **임의 좌표에 대한 분석이 아니다.** 3I/ATLAS는 움직이는 천체라 고정 좌표로 찾을 수 없고, 전용 데이터셋으로만 동작한다.
- 그래서 추가 분석 목록에 두면 대부분의 좌표에서 항상 비활성화된다. 하늘에 "3I/ATLAS" 특별 핀을 두고, 클릭하면 이 화면으로 가는 방식을 권장한다.
- 분자 밴드 세기 해석은 단순화한 값임을 표시한다.

## 7. 검증

공개된 3I/ATLAS SPHEREx 관련 발표 내용과 경향이 맞는지 확인한다.
