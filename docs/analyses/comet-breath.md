# Comet Breath (성간 혜성의 숨결)

| 항목 | 내용 |
| --- | --- |
| ID | `comet-breath` |
| 상태 | **1차 구현됨** (분석 패널 "Additional analyses"에서 열림) · 화면 배치 논의 필요 |
| 담당 | 김재현 (`rreenactt`) |
| 출력 종류 | view, chart |
| 최소 SPHEREx 방문 횟수 | 해당 없음 (전용 데이터셋) |
| 적용 대상 | **성간 혜성 3I/ATLAS만** (패널 지점과 무관) |
| 화면 배치 | 지금은 추가 분석 목록("3I/ATLAS only"), 하늘의 3I/ATLAS 특별 핀에서 진입 권장 |
| 데이터 | IRSA 3I/ATLAS 전용 관측 목록, SPHEREx DR1 L2b, 논문 방출률 |

## 1. 무엇을 알려주나

성간 혜성 3I/ATLAS를 SPHEREx가 근일점 전(2025-08)과 후(2025-12)에 찍은 영상과 스펙트럼을 보여주고, 물·CO₂·CO 방출이 두 시기 사이에 어떻게 달라졌는지 논문의 방출률과 함께 비교한다.

## 2. 왜 필요한가

- "시간에 따른 변화"라는 챌린지 주제를 움직이는 천체로 보여준다. SPHEREx의 102개 파장이 분자 밴드(CO₂ 4.26 µm, CO 4.65 µm 등)를 직접 잡는 장점을 보여주기 좋다.
- IRSA가 이미 정리한 전용 데이터셋이라 데이터 준비 부담이 작다.
- 고정 좌표로는 찾을 수 없는 이동 천체를 관측 시점별 예측 좌표로 다루는 예시다 (절대 원칙 6).

## 3. 입력 데이터

- **관측 목록:** IRSA 3I/ATLAS 전용 목록(259행, `spherex_qr2`)에서 노출과 시점별 혜성 예측 좌표
- **픽셀:** 목록의 QR2 DataLink는 지금 파일을 돌려주지 않아, 같은 `obs_id`·검출기를 DR1 DataLink로 조회해 `#this` 이미지가 확인된 것만 쓴다. AWS 공개 버킷 L2b에서 바이트 범위로 읽는다.
- **방출률:** 직접 계산하지 않고 논문값을 인용한다 — Lisse+2025b (arXiv:2512.07318 v3), Lisse+2026 (arXiv:2601.06759 v2). 초기 분석 arXiv:2508.15469 v2는 "대체됨"으로 표시.
- **JPL Horizons:** 관측 시각별 거리(관측 근거 탭)

## 4. 방법

1. **시기:** SPHEREx 관측은 2025-08-01–15(근일점 전)와 2025-12-08–14(근일점 후)뿐이라 두 기간으로 나눈다. "근일점 부근"은 관측이 없어 만들지 않는다.
2. **측광:** 관측마다 혜성 예측 좌표에 2px 조리개(논문 12″) + 10–29px 배경 고리(논문 1′–3′, 3σ 클리핑). 혜성 픽셀의 파장을 `WCS-WAVE`로 계산해 그 파장에 점을 놓는다.
3. **OUTLIER 처리 ([결정 #28](../decisions.md)):** 파이프라인이 혜성 코마 중심을 OUTLIER로 표시한다. 처음에 이를 가려 CO₂ 플럭스를 약 93% 낮게 쟀다. 측정 원에서는 가리지 않고 배경 고리에서만 가린다.
4. **스펙트럼:** 여러 날짜의 점을 모은 "기간 합성 스펙트럼"으로 그리고 보간하지 않는다. 품질 점검을 통과한 관측만 쓴다.
5. **방출률 비교:** 논문값을 논문의 분석 기간에만 연결하고, 상한값은 화살표로 구분한다. 12월 "약 40배"는 논문 표현 그대로 둔다.

## 5. 출력

- **탭:** 관측 영상 / 스펙트럼 / 방출률 비교 / 관측 근거
- 위쪽의 기간(8월·12월)·검출기·날짜 슬라이더를 탭끼리 공유
- 스펙트럼: 파장(µm) 대 플럭스(mJy), 기간별 색

## 6. 한계와 주의

- 임의 좌표 분석이 아니다. 패널 지점과 무관하게 전용 데이터셋을 연다.
- 측광값은 거리 보정(rₕ=Δ=1 au)을 하지 않아 논문 그림과 절대값을 바로 비교할 수 없다.
- 분자 밴드 세기를 직접 계산하지 않는다. 방출률은 논문 인용이다.

## 7. 검증

- FLAGS 압축 해제를 IRSA 잘라내기와 대조해 5,112픽셀 일치.
- 8월 12개 중 9개, 12월 24개 모두 품질 통과.
- 12월 CO 구간(4.65 μm) 46 mJy, CO₂ 구간(4.21 μm) 39 mJy가 주변 연속광보다 높다 — 논문의 CO₂·CO 방출 경향과 같은 방향.
