# Comet Breath (성간 혜성의 숨결)

| 항목 | 내용 |
| --- | --- |
| ID | `comet-breath` |
| 상태 | 확정 · **화면 배치 논의 필요** · **1차 구현됨** (독립 팝업) |
| 담당 | 김재현 (`rreenactt`) |
| 출력 종류 | view, chart |
| 최소 SPHEREx 방문 횟수 | 해당 없음 (전용 데이터셋 사용) |
| 적용 대상 | **성간 혜성 3I/ATLAS만** |
| 화면 배치 | **특별 대상 페이지 권장** (하늘의 3I/ATLAS 핀에서 진입) |
| 난이도 | 중 |
| 예상 소요 시간 | 미정 |

## 1. 무엇을 알려주나

성간 혜성 3I/ATLAS의 SPHEREx 관측으로 물·CO₂·CO 방출이 관측 시기(근일점 전·부근·후)별로 어떻게 바뀌는지 보여준다.

## 2. 왜 필요한가

IRSA에 이미 정리되어 공개된 화제성 큰 전용 데이터셋이라 데이터 준비 시간이 짧다. "시간에 따른 변화"라는 챌린지 주제와 맞고, 102개 파장의 가치를 보여주기 좋다.

## 3. 입력 데이터

- IRSA SPHEREx 3I/ATLAS 전용 스펙트럼 이미지
- JPL Horizons (태양과의 거리, 관측 시각별 위치)

## 4. 방법

1. 3I/ATLAS 전용 영상을 로드하고 코마 영역 스펙트럼을 추출한다.
2. 물·CO₂·CO 분자 밴드 세기를 관측 시기별로 비교한다.
3. 태양과의 거리 변화와 연동한 그래프를 만든다.

## 5. 출력

- **view:** 혜성 이미지와 시기 탭 (근일점 전 / 부근 / 후)
- **chart:** 분자별 밴드 세기 막대, 태양 거리 대비 그래프

## 6. 실행 조건과 한계

- **임의 좌표에 대한 분석이 아니다.** 3I/ATLAS는 움직이는 천체라 고정 좌표로 찾을 수 없고, 전용 데이터셋으로만 동작한다.
- 그래서 추가 분석 목록에 두면 대부분의 좌표에서 항상 비활성화된다. 하늘에 "3I/ATLAS" 특별 핀을 두고, 클릭하면 이 화면으로 가는 방식을 권장한다.
- 분자 밴드 세기 해석은 단순화한 값임을 표시한다.

## 7. 검증

공개된 3I/ATLAS SPHEREx 관련 발표 내용과 경향이 맞는지 확인한다.

## 8. 참고 자료

- 출처: 팀 아이디어 쇼케이스 문서
- [IRSA SPHEREx 3I/ATLAS](https://irsa.ipac.caltech.edu/data/SPHEREx/docs/comet3iatlas/index.html)

## 9. 구현 기록 (2026-11-14)

- **위치:** 홈의 `Comet Breath` 팝업 (`app/_components/comet-breath/`). 탭: 관측 영상 / 스펙트럼 / 방출률 비교 / 관측 근거. 위쪽의 기간(8월·12월)·검출기·날짜 슬라이더를 탭끼리 공유한다.
- **시기:** SPHEREx 관측은 2025-08-01–15(근일점 전)와 2025-12-08–14(근일점 후)뿐이라 "근일점 부근" 탭은 없다.
- **데이터:** IRSA 3I/ATLAS 전용 관측 목록(259행, `spherex_qr2`)으로 노출·혜성 예측 좌표를 얻는다. 목록의 QR2 DataLink는 지금 파일을 돌려주지 않아, 같은 `obs_id`·검출기를 DR1 DataLink로 조회해 `#this` 이미지가 확인된 것만 쓴다. 픽셀은 AWS 공개 버킷의 L2b 파일에서 바이트 범위로 읽는다(FLAGS RICE_1 압축 해제를 IRSA cutout과 대조해 5,112픽셀 일치 확인).
- **스펙트럼:** 관측마다 2px 조리개(논문 12″) + 10–29px 배경 고리(논문 1′–3′, 3σ 클리핑)로 측광하고, 혜성 픽셀의 파장을 `WCS-WAVE`로 계산해 배치한다. 여러 날짜를 모은 "기간 합성 스펙트럼"으로 표시하고 보간하지 않는다. 8월 12개 중 9개, 12월 24개 모두 품질 통과. 12월 CO 구간(4.65 μm) 46 mJy, CO₂ 구간(4.21 μm) 39 mJy가 주변 연속광보다 높다. 측광값은 거리 보정(rₕ=Δ=1 au)을 하지 않아 논문 그림과 절대값을 바로 비교할 수 없다.
- **OUTLIER 발견:** 파이프라인이 혜성 코마 중심을 OUTLIER로 표시한다. 처음에 이를 가려 CO₂ 플럭스를 약 93% 낮게 쟀다. 측정 원에서는 OUTLIER를 가리지 않고 배경 고리에서만 가린다(결정 #26).
- **방출률:** 직접 계산하지 않고 논문값을 인용한다(Lisse+2025b arXiv:2512.07318 v3, Lisse+2026 arXiv:2601.06759 v2, 초기 분석 arXiv:2508.15469 v2는 "대체됨"). 값은 논문의 분석 기간에만 연결하고, 상한값은 화살표로 구분한다. 12월 "약 40배"는 논문 표현 그대로 둔다.
- **남은 일:** 3I/ATLAS 특별 핀에서 진입(화면 배치 결정), 화면 문구 영어화, 분자 밴드 세기 직접 계산, Horizons 거리로 플럭스 보정.
