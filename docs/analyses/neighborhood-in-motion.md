# Neighborhood in Motion (움직이는 이웃 별)

| 항목 | 내용 |
| --- | --- |
| ID | `neighborhood-in-motion` |
| 상태 | 확정 · **1차 구현됨** (3D 하늘 위 버튼으로 여는 팝업, 분석 패널 통합 전) |
| 담당 | 김재현 (`rreenactt`) |
| 출력 종류 | view |
| 최소 SPHEREx 방문 횟수 | 1 |
| 적용 대상 | 시차를 아는 근접 천체 (Barnard's Star, Epsilon Indi B, WISE 0855 등) |
| 화면 배치 | 추가 분석 목록 (조건이 맞을 때만 활성화) |
| 난이도 | 중 |
| 예상 소요 시간 | 미정 |

## 1. 무엇을 알려주나

근접 천체를 3D 공간에 놓고, 수천 년 앞뒤의 위치까지 움직여 보여준다. SPHEREx 관측 시점의 실제 위치를 궤적 위에 표시한다.

## 2. 왜 필요한가

2D 블링크의 작은 이동을 "실제로 우주에서 어떻게 움직이는가"라는 3D 이야기로 확장한다. 일반 관객 대상 발표에 강하고, 우리 기획의 3D 하늘 뷰와 자연스럽게 이어진다.

## 3. 입력 데이터

- Gaia DR3 (시차, 고유운동), SIMBAD
- SPHEREx 관측 시점과 위치
- WISE 0855는 가시광으로 너무 어두워 Gaia에 없으므로 문헌 시차를 쓴다.

## 4. 방법

1. 시차와 고유운동으로 3D 좌표를 계산한다 (가능하면 시선속도도 반영).
2. 시간 슬라이더로 과거·미래 위치를 외삽한다.
3. SPHEREx 관측 시점의 실제 위치를 궤적 위에 표시한다.

## 5. 출력

- **한 줄 요약 예시:** "거리 1.83 pc · 수천 년 궤적 3D 보기"
- **view:** 3D 공간, 별마다 궤적 꼬리, "지구에서 본 모습" / "위에서 본 모습" 전환

## 6. 실행 조건과 한계

- 시차를 아는 천체에서만 동작한다. 조건이 안 맞으면 목록에서 비활성화하고 이유를 보여준다.
- 수천 년 외삽은 단순 직선 운동 가정임을 표시한다.

## 7. 검증

Barnard's Star, Epsilon Indi B, WISE 0855의 위치·거리가 문헌값과 맞는지 확인한다.

## 8. 참고 자료

- 출처: 팀 아이디어 쇼케이스 문서
- [Gaia 미션 데이터 (MAST)](https://archive.stsci.edu/missions-and-data/gaia)

## 9. 구현 기록 (2026-11-14)

- **위치:** 3D 하늘 위 `Neighborhood in Motion` 버튼 (`app/_components/neighborhood/`). 탭: 3D map / Sky view / SPHEREx / Data & model. 시간 막대는 "관측 부근(1800–2250)"과 "외삽(기원전 10,000 – 서기 32,000, 교육용)"을 나눠 둔다.
- **천체 (21개):** Gaia DR3에서 시차 > 280 mas(약 3.6 pc 이내) 18개와 ε Indi A·B를 매번 조회한다(ESA Gaia Archive 우선, 결정 #27). Gaia에는 이름이 없어, `source_id`마다 위치·시차·밝기로 확인한 이름을 붙였다(`app/_lib/nim/catalog.ts`). WISE 0855는 Gaia에 없어 Luhman & Esplin 2014 (arXiv:1409.5899v1) Table 2의 시차 0.433±0.015″·고유운동 (−8.10±0.02, 0.70±0.02)″/년과 Table 1의 2014.50 Spitzer 위치를 쓴다.
- **측정값과 가정 분리:** 시선속도가 없는 6개(WISE 0855, Wolf 359, Sirius B, ε Eridani, Ross 128, ε Indi B)는 값을 0으로 저장하지 않고, 경로를 계산할 때만 가정값(기본 0 km/s, 사용자가 바꿀 수 있음)을 쓴다. 이런 천체의 미래 경로는 점선·주황색이다.
- **주의 표시:** RUWE가 큰 천체(Luyten 726-8 두 성분 10–12, ε Indi B 4.3, ε Eridani 2.7, Sirius B 2.4)에 쌍성 영향을 적는다. ε Indi B는 Ba+Bb 미분해 단일 해이며 주성(A)의 운동을 빌려 쓰지 않고, 궤도 운동은 그리지 않는다. Luyten 726-8 성분은 A/B로 단정하지 않는다.
- **모델:** 태양계 질량중심 ICRS에서 등속 직선 운동 r(t) = r(t₀) + v(t − t₀), 거리 = 1000/ϖ. 3D 표시는 북극 위·1 단위 = 1 pc로 축만 바꾼다. 측정 오차는 Gaia 상관계수(ϖ–μα, ϖ–μδ, μα–μδ)로 공분산을 만들어 표본을 뽑고, 시선속도는 독립으로, 문헌값은 독립 오차로 다룬다.
- **검증:** 기준 시점(2016.0)에서 좌표·거리 재현(차이 0). 짧은 기간에서 3D 모델과 선형 고유운동의 차이 0.06–0.16″(투영 가속 효과). Barnard's Star 최근접 서기 11,736년·1.155 pc(3.77광년)로 문헌의 약 3.75광년·서기 약 11,700년과 일치, 측정 오차 범위(5–95%) 11,732–11,740년. 프록시마 최근접 서기 28,650년·0.958 pc(3.12광년).
- **SPHEREx 연결:** 2025.8 모델 위치로 SPHEREx DR1을 찾고, 고른 노출의 관측 시각으로 위치를 다시 계산해 그 노출의 원본 픽셀에서 비교한다(Fake Planet Lab 코드 재사용). 모델 위치(파란 원)와 밝기 중심(노란 +)을 구분하고, "검출"이라고 하지 않고 S/N과 거리만 보인다. 결과: Ross 128 D6 S/N 338·중심 1.5″, Barnard's Star D6 S/N 242·중심 4.1″ (픽셀 6.15″). D2에서는 두 별 모두 중심이 포화되어 측정 불가라서 기본 검출기를 D6으로 했다. WISE 0855는 한 노출(D6, 5.0 µm)에서 S/N 1.7로 중심을 잡지 못했다.
- **한계:** 관측자(지구 궤도) 시차는 넣지 않았다(최대 0.77″, SPHEREx 픽셀보다 훨씬 작음). 은하 중력·쌍성 궤도 없음. 3.6 pc보다 먼 천체와 Gaia DR3에 없는 밝은 별(α Cen A/B, Sirius A)은 목록에 없다.
