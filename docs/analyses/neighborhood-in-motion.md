# Neighborhood in Motion (움직이는 이웃 별)

| 항목 | 내용 |
| --- | --- |
| ID | `neighborhood-in-motion` |
| 상태 | 확정 |
| 담당 | |
| 출력 종류 | view |
| 최소 SPHEREx 방문 횟수 | 1 |
| 적용 대상 | 시차를 아는 근접 천체 (Barnard's Star, Epsilon Indi B, WISE 0855 등) |
| 화면 배치 | 추가 분석 목록 (조건이 맞을 때만 활성화) |
| 난이도 | 중 |
| 예상 소요 시간 | 미정 |

## 1. 무엇을 알려주나

근접 천체를 3D 공간에 놓고, 수천 년 앞뒤의 위치까지 움직여 보여준다. SPHEREx 관측 시점의 실제 위치를 궤적 위에 표시한다.

## 2. 왜 필요한가

2D 블링크의 작은 이동을 "실제로 우주에서 어떻게 움직이는가"라는 3D 이야기로 확장한다. 일반 관객 대상 발표에 강하고, 우리 기획의 3D 하늘 뷰와 자연스럽게 이어진다.

## 3. 입력 데이터

- Gaia DR3 (시차, 고유운동), SIMBAD
- SPHEREx 관측 시점과 위치
- WISE 0855는 가시광으로 너무 어두워 Gaia에 없으므로 문헌 시차를 쓴다.

## 4. 방법

1. 시차와 고유운동으로 3D 좌표를 계산한다 (가능하면 시선속도도 반영).
2. 시간 슬라이더로 과거·미래 위치를 외삽한다.
3. SPHEREx 관측 시점의 실제 위치를 궤적 위에 표시한다.

## 5. 출력

- **한 줄 요약 예시:** "거리 1.83 pc · 수천 년 궤적 3D 보기"
- **view:** 3D 공간, 별마다 궤적 꼬리, "지구에서 본 모습" / "위에서 본 모습" 전환

## 6. 실행 조건과 한계

- 시차를 아는 천체에서만 동작한다. 조건이 안 맞으면 목록에서 비활성화하고 이유를 보여준다.
- 수천 년 외삽은 단순 직선 운동 가정임을 표시한다.

## 7. 검증

Barnard's Star, Epsilon Indi B, WISE 0855의 위치·거리가 문헌값과 맞는지 확인한다.
