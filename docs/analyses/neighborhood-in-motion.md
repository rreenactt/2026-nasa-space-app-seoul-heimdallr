# Neighborhood in Motion (움직이는 이웃 별)

| 항목 | 내용 |
| --- | --- |
| ID | `neighborhood-in-motion` |
| 상태 | **1차 구현됨** (분석 패널 "Additional analyses"에서 열림) |
| 담당 | 김재현 (`rreenactt`) |
| 출력 종류 | view |
| 최소 SPHEREx 방문 횟수 | 1 |
| 적용 대상 | 태양에서 약 3.6 pc 안의 천체 21개 (지점에서 0.1° 안이면 그 천체, 아니면 가장 가까운 천체와 거리를 알림) |
| 화면 배치 | 추가 분석 목록 → "Download data" → "Open" |
| 데이터 | Gaia DR3, 문헌값(WISE 0855), SPHEREx DR1 |

## 1. 무엇을 알려주나

태양 근처 별과 갈색왜성 21개를 측정된 거리·운동으로 3D 공간에 놓고, 시간을 앞뒤로 움직여 보여준다. 고른 천체의 SPHEREx 관측 시점 위치를 모델로 계산해, 실제 SPHEREx 영상에서 그 자리에 천체가 있는지 비교한다.

## 2. 왜 필요한가

- 블링크에서 보이는 몇 ″의 이동이 "우주에서 실제로 어떻게 움직이는 것인지"를 3D로 연결한다. 일반 관객에게 설명하기 좋다.
- "모델 예측 위치 vs 영상 밝기 중심"을 나란히 보여줘, 움직이는 천체의 좌표를 관측 시점과 함께 다루는 법(절대 원칙 6)을 직접 보여준다.

## 3. 입력 데이터

- **Gaia DR3:** 시차 > 280 mas(약 3.6 pc 이내) 18개와 ε Indi A·B를 매번 조회 (ESA Gaia Archive 우선, [결정 #27](../decisions.md)). 위치, 시차, 고유운동, 시선속도, 오차와 상관계수, RUWE.
- **이름:** Gaia에는 이름이 없어 `source_id`마다 위치·시차·밝기로 확인한 이름을 붙였다 (`app/_lib/nim/catalog.ts`).
- **WISE 0855:** Gaia에 없다. Luhman & Esplin 2014 (arXiv:1409.5899v1) Table 2의 시차 0.433±0.015″·고유운동 (−8.10±0.02, 0.70±0.02)″/년과 Table 1의 2014.50 Spitzer 위치를 쓴다.
- **SPHEREx DR1:** Fake Planet Lab과 같은 경로.

## 4. 방법

1. **모델:** 태양계 질량중심 ICRS에서 등속 직선 운동 r(t) = r(t₀) + v(t − t₀), 거리 = 1000/ϖ. 3D 표시는 북극 위, 1 단위 = 1 pc로 축만 바꾼다.
2. **측정값과 가정 분리:** 시선속도가 없는 6개(WISE 0855, Wolf 359, Sirius B, ε Eridani, Ross 128, ε Indi B)는 값을 0으로 저장하지 않는다. 경로를 계산할 때만 가정값(기본 0 km/s, 사용자가 바꿀 수 있음)을 쓰고, 미래 경로를 점선·주황색으로 그린다.
3. **불확실성:** Gaia 상관계수(ϖ–μα, ϖ–μδ, μα–μδ)로 공분산을 만들어 표본을 뽑는다. 시선속도와 문헌값은 독립 오차로 다룬다.
4. **주의 표시:** RUWE가 큰 천체(Luyten 726-8 두 성분 10–12, ε Indi B 4.3, ε Eridani 2.7, Sirius B 2.4)에 쌍성 영향을 적는다. ε Indi B는 Ba+Bb 미분해 단일 해이며 주성 운동을 빌려 쓰지 않는다.
5. **SPHEREx 연결:** 2025.8 모델 위치로 DR1을 검색하고, 고른 노출의 관측 시각으로 위치를 다시 계산해 그 노출의 원본 픽셀에서 비교한다. 모델 위치(파란 원)와 밝기 중심(노란 +)을 구분하고, "검출"이라 하지 않고 S/N과 거리만 보인다. 기본 검출기는 D6 (D2에서는 밝은 별 중심이 포화).
6. **시간 막대:** "관측 부근(1800–2250)"과 "외삽(기원전 10,000 – 서기 32,000, 교육용)"을 나눈다.

## 5. 출력

- **탭:** 3D map / Sky view / SPHEREx / Data & model
- 3D 지도와 하늘 시점, 천체별 궤적, 최근접 시각·거리와 오차 범위
- SPHEREx 영상 위 모델 위치·밝기 중심·S/N

## 6. 한계와 주의

- 직선 운동 가정이다. 은하 중력, 쌍성 궤도 운동은 넣지 않았다. 수천 년 외삽은 교육용으로 표시한다.
- 관측자(지구 궤도) 시차는 넣지 않았다(최대 0.77″, SPHEREx 픽셀보다 훨씬 작음).
- 3.6 pc보다 먼 천체와 Gaia DR3에 없는 밝은 별(α Cen A/B, Sirius A)은 목록에 없다.

## 7. 검증

- 기준 시점(2016.0)에서 좌표·거리 재현 (차이 0). 짧은 기간에서 3D 모델과 선형 고유운동의 차이 0.06–0.16″(투영 가속 효과).
- Barnard's Star 최근접 서기 11,736년·1.155 pc(3.77광년), 문헌의 약 3.75광년·서기 약 11,700년과 일치. 오차 범위(5–95%) 11,732–11,740년.
- 프록시마 최근접 서기 28,650년·0.958 pc.
- SPHEREx: Ross 128 D6 S/N 338·중심 1.5″, Barnard's Star D6 S/N 242·중심 4.1″ (픽셀 6.15″). WISE 0855는 한 노출(D6, 5.0 µm)에서 S/N 1.7로 중심을 잡지 못함 → 그대로 표시.
