# Blink Arena (하늘 판정 게임)

| 항목 | 내용 |
| --- | --- |
| ID | `blink-arena` |
| 상태 | 확정 · **화면 배치 논의 필요** |
| 담당 | |
| 출력 종류 | view |
| 최소 방문 횟수 | 2 |
| 적용 대상 | 좌표 하나가 아니라 여러 후보 카드를 연속으로 판정 |
| 화면 배치 | **별도 화면(게임 모드) 권장** · 기능 B(사용자 평가)와 연결 |
| 난이도 | 하~중 |
| 예상 소요 시간 | 해당 없음 (즉시 시작) |

## 1. 무엇을 알려주나

누구나 SPHEREx 블링크 카드를 보고 "움직였나?"를 빠르게 판정하는 시민과학 게임이다. 정답을 아는 가짜 천체를 섞어 참가자의 정확도를 측정한다.

## 2. 왜 필요한가

챌린지가 요구하는 "대중용 웹 도구"에 정면으로 맞는다. 판정 데이터가 쌓일수록 기능 A 후보의 질이 올라가는 구조라, 기능 A·B를 강화한다.

## 3. 입력 데이터

- SPHEREx 컷아웃 (기능 A 후보 위치)
- Gaia DR3 (정적 별 마스크)
- 합성 주입 데이터 (정답을 아는 가짜 이동체, 우주선 흔적 같은 잡음 카드)

## 4. 방법

1. 기능 A 후보와 합성 카드를 섞어 판정 덱을 만든다.
2. 카드마다 블링크를 보여주고 기능 B와 같은 3지선다 판정("움직인다" / "안 움직인다" / "잡음·결함")을 받는다.
3. 합성 카드의 정답률로 참가자별 신뢰도 가중치를 계산한다.
4. 가중치를 반영한 판정이 모이면 후보를 "주목할 후보" 큐로 올린다.

## 5. 출력

- **view:** 카드형 판정 화면 (모바일 우선), 연속 정답 스트릭, 정확도, 라운드 수
- 판정 결과는 기능 B의 평가 DB에 저장한다.

## 6. 실행 조건과 한계

- **좌표 하나에 대한 분석이 아니라 여러 후보를 도는 모드**라서, 분석 패널의 추가 분석 목록보다는 메인 화면의 별도 진입점("판정 게임")이 자연스럽다.
- 3지선다 판정이 기능 B와 같으므로, 평가 DB와 정리 규칙(기획서 7장)을 공유한다. 이때 합성 카드 정답률 기반 가중치를 정리 규칙에 반영할지 정해야 한다.
- 합성 카드는 반드시 합성 데이터로 관리하고, 실제 후보와 섞여 집계되지 않게 한다.

## 7. 검증

연습 모드(전부 합성 카드)로 판정 흐름과 정확도 계산을 확인한다.
