# Sky Sonata (들리는 하늘)

| 항목 | 내용 |
| --- | --- |
| ID | `sky-sonata` |
| 상태 | 확정 · **1차 구현됨** (분석 패널 토글에서 열림) |
| 담당 | 김재현 (`rreenactt`) |
| 출력 종류 | audio |
| 최소 SPHEREx 방문 횟수 | 1 (변화 알림은 2 이상) |
| 적용 대상 | 모든 좌표 |
| 화면 배치 | 추가 분석 목록 · 키보드 접근 지원 |
| 난이도 | 하 |
| 예상 소요 시간 | 즉시 (브라우저에서 생성) |

## 1. 무엇을 알려주나

하늘의 변화를 소리로 들려준다. 위치는 좌우, 밝기는 음량, 높이는 음높이로 바꾸고, 변화한 점은 다른 음색으로 알린다.

## 2. 왜 필요한가

화면을 보기 어려운 사용자도 하늘 탐색에 참여할 수 있다. 적은 개발량으로 확실히 다른 결과물이고, 접근성이라는 별도 심사 관점을 확보한다.

## 3. 입력 데이터

- 기본 분석 결과: 블링크 시퀀스(방문별 컷아웃)
- Gaia DR3 (알려진 별 구분)

## 4. 방법

1. 블링크 시퀀스의 천체 위치·밝기를 추출한다.
2. Web Audio로 스테레오 오디오를 만든다 (좌우 = 위치, 음량 = 밝기, 음높이 = 높이).
3. 방문 사이에 변한 점은 다른 음색으로 재생한다.
4. 키보드만으로 하늘 조각을 탐색할 수 있게 한다.

## 5. 출력

- **한 줄 요약 예시:** "소리로 재생 · 변화한 점 1개 (다른 음색)"
- **audio:** 재생/정지, 재생 길이 조절
- 재생 중인 위치를 이미지에 동기화해 강조한다.

## 6. 실행 조건과 한계

- 소리가 나므로 재생 전 안내하고, 이어폰 사용을 권장한다.
- 스크린 리더와 키보드 조작을 함께 고려한다.

## 7. 검증

변화가 확실한 테스트 대상(소행성 후보, 변광성)에서 변화음이 들리는지 확인한다.

## 8. 참고 자료

- 출처: 팀 아이디어 쇼케이스 문서

## 9. 구현 기록 (2026-11-14)

- **위치:** 분석 패널 오른쪽 "Additional analyses"의 토글 (`app/_components/analyses/additional-analyses.tsx`). 패널의 ra/dec·대상 이름·출처를 초기 대상으로 받아 열린다. 예전 `?sonata=` 링크는 패널을 연 뒤 이 분석을 그 소리 설정으로 자동으로 연다 (`app/_components/sky-sonata/`). 탭: Listen / Practice / Rules & sources. 화면 맨 위에 "규칙에 따른 변환이며 우주에서 녹음한 소리가 아님"을 적는다.
- **데이터:** Fake Planet Lab과 같은 경로로 SPHEREx DR1 노출을 찾고 원본 픽셀(IMAGE·ZODI·VARIANCE·FLAGS·WCS-WAVE)을 바이트 범위로 읽는다. 저장하지 않는다.
- **광원(원본 픽셀, 화면 대비와 무관):** IMAGE − ZODI − 하늘 중앙값(3σ 클리핑)에서 5σ 이상 봉우리이면서 3×3 합도 S/N ≥ 5인 점. 밝기는 3×3 합(mJy). NONFUNC·MISSING_DATA·HOT·COLD는 건너뛰고, TRANSIENT·SNOWBALL은 봉우리로 쓰지 않는다. 포화 플래그 픽셀이 이어진 영역은 하나의 "포화 광원"으로 묶는다(Barnard's Star 핵 57픽셀 → 1개).
- **소리 규칙(`sonata-rules-1`, 고정·설명):** 좌우 = 2x − 1, 음높이 f = fMin·(fMax/fMin)^(1−y)(위가 높음, 기본 220–1760 Hz), 밝기 = 로그 압축 음량(상한 있음), 가로 위치 = 스캔 시점(기본 6초). 포화 광원은 네모파(밝기 신뢰 불가), 자료 없음은 낮은 이중 클릭. 측정값과 소리 설정을 분리한다.
- **A·B 비교:** 같은 검출기의 두 노출(기본: 첫 방문과 마지막 방문)을 같은 규칙과 **공유 밝기 범위**(A·B의 광원을 합쳐 계산, 각자 정규화하지 않음)로 재생한다. 두 노출의 시야 중심 파장이 대역폭 밖으로 다르면 경고하고, 설정을 바꾸면 다시 들으라고 알린다. 스캔 시간과 관측 시간이 다름을 적는다.
- **접근성:** 소리는 "Start sound"를 누른 뒤에만, 낮은 기본 음량, 항상 보이는 "Stop all sound". 영상에 초점을 두고 방향키로 지점 이동(Shift = 작은 걸음), Enter로 다시 듣기, N/P로 다음·이전 광원. 모든 소리를 `aria-live` 문장(좌표·밝기·음높이·좌우)과 텍스트 광원 표로도 제공. 라벨·`aria-valuetext`가 있는 슬라이더, 모노 모드. 재생할 광원 수에 상한이 있음을 알리고 "소리 없음 ≠ 빈 하늘"을 적는다.
- **연습:** 좌·우, 위·아래, 같은 자리의 어두움·밝음 세 가지 합성 예제. "Synthetic practice — not observation data"로 실제 관측과 구분한다.
- **공유:** `/?sonata=ra,dec,fMin,fMax,scan,mono,fluxLo,fluxHi`로 영역과 소리 규칙을 공유한다. 광원·소리 이벤트 JSON 복사.
- **검증:** 규칙 시험 — 좌우만 다른 두 점은 pan −0.8/+0.8(음높이·음량 같음), 위아래만 다른 두 점은 1430/271 Hz(나머지 같음), 밝기만 다른 두 점은 음량 0.07/0.29(나머지 같음), 같은 영상을 A·B로 넣으면 이벤트가 완전히 같음. 브라우저 — 스캔 시 15음 예약·재생선 표시, 정지 시 남은 예약 11음 즉시 취소, A→B 15+13음 순서 재생, 방향키·N 키 안내 문장 확인.
- **안 한 것:** 방문 사이 "변한 점"의 자동 알림음(4절 3번). 변화 후보를 계산하려면 정렬·파장·품질·PSF 조건 확인이 먼저 필요해 미뤘다. 지금은 사용자가 A·B를 듣고 판단한다. 오디오 파일 내보내기, 사용자 평가도 아직 없다.
