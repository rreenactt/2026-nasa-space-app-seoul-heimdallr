# Sky Sonata (들리는 하늘)

| 항목 | 내용 |
| --- | --- |
| ID | `sky-sonata` |
| 상태 | **1차 구현됨** (분석 패널 "Additional analyses"에서 열림) |
| 담당 | 김재현 (`rreenactt`) |
| 출력 종류 | audio |
| 최소 SPHEREx 방문 횟수 | 1 (A·B 비교는 2 이상) |
| 적용 대상 | 모든 좌표 |
| 화면 배치 | 추가 분석 목록 → "Run" → 다 받으면 패널 왼쪽 탭으로 열림 (결정 #42), 키보드만으로 조작 가능 |
| 데이터 | IRSA SPHEREx DR1, AWS L2b 바이트 범위 |

## 1. 무엇을 알려주나

SPHEREx 영상 속 광원을 정해진 규칙에 따라 소리로 바꿔 들려준다. 위치는 좌우와 음높이, 밝기는 음량이 된다. 같은 지점의 두 관측(A·B)을 같은 규칙으로 이어 들어, 자리를 옮기거나 밝기가 바뀐 광원을 귀로 비교할 수 있다.

## 2. 왜 필요한가

- 화면을 보기 어려운 사용자도 하늘 비교에 참여할 수 있다 (접근성).
- 소리는 규칙을 공개한 변환이라, "우주에서 녹음한 소리"로 오해하지 않게 화면 맨 위에 적는다.

## 3. 입력 데이터

- Fake Planet Lab과 같은 경로로 찾은 SPHEREx DR1 노출의 원본 픽셀: IMAGE, ZODI, VARIANCE, FLAGS, WCS-WAVE
- 기본 A·B: 같은 검출기(D3 우선)의 첫 방문과 마지막 방문 노출
- 저장하지 않는다.

## 4. 방법

1. **광원 찾기 (원본 픽셀, 화면 대비와 무관):** IMAGE − ZODI − 하늘 중앙값(3σ 클리핑)에서 5σ 이상 봉우리이면서 3×3 합도 S/N ≥ 5인 점. 밝기는 3×3 합(mJy).
2. **플래그:** NONFUNC·MISSING_DATA·HOT·COLD는 건너뛰고, TRANSIENT·SNOWBALL은 봉우리로 쓰지 않는다. 포화 픽셀이 이어진 영역은 하나의 "포화 광원"으로 묶는다(Barnard's Star 핵 57픽셀 → 1개).
3. **소리 규칙 (`sonata-rules-1`, 고정·화면에 설명):**
   - 좌우 = 2x − 1
   - 음높이 f = fMin·(fMax/fMin)^(1−y), 위가 높음 (기본 220–1760 Hz)
   - 음량 = 밝기의 로그 압축 (상한 있음)
   - 가로 위치 = 스캔 시점 (기본 6초에 왼쪽 → 오른쪽)
   - 포화 광원은 네모파(밝기 신뢰 불가), 자료 없음은 낮은 이중 클릭
4. **A·B 비교:** 두 노출을 같은 규칙과 **공유 밝기 범위**(A·B 광원을 합쳐 계산, 각자 정규화하지 않음)로 재생한다. 두 노출의 시야 중심 파장이 대역폭 밖으로 다르면 경고한다. 스캔 시간은 관측 시간과 다르다고 적는다.
5. **접근성:** "Start sound"를 누른 뒤에만 소리, 낮은 기본 음량, 항상 보이는 "Stop all sound". 영상에 초점을 두고 방향키로 지점 이동(Shift = 작은 걸음), Enter로 다시 듣기, N/P로 다음·이전 광원. 모든 소리를 `aria-live` 문장과 텍스트 광원 표로도 제공. 모노 모드.
6. **연습:** 좌·우, 위·아래, 같은 자리의 어두움·밝음 세 가지 합성 예제. "Synthetic practice — not observation data"로 구분한다.

## 5. 출력

- **탭:** Listen / Practice / Rules & sources
- 재생·정지, 스캔 길이·음높이 범위·모노 설정, 재생선 표시
- 광원 표와 소리 이벤트 JSON 복사, 공유 링크 `/?sonata=ra,dec,fMin,fMax,scan,mono,fluxLo,fluxHi`

## 6. 한계와 주의

- 재생할 광원 수에 상한이 있다. "소리 없음 ≠ 빈 하늘"이라고 적는다.
- 방문 사이에 "변한 점"을 자동으로 다른 음색으로 알리는 기능은 없다. 변화 후보를 계산하려면 정렬·파장·품질·PSF 조건 확인이 먼저 필요해 미뤘다. 지금은 사용자가 A·B를 듣고 판단한다.

## 7. 검증

- 규칙 시험: 좌우만 다른 두 점 → pan −0.8/+0.8(음높이·음량 같음), 위아래만 다른 두 점 → 1430/271 Hz, 밝기만 다른 두 점 → 음량 0.07/0.29, 같은 영상을 A·B로 넣으면 이벤트가 완전히 같음.
- 브라우저: 스캔 시 15음 예약·재생선 표시, 정지 시 남은 예약 11음 즉시 취소, A→B 15+13음 순서 재생, 방향키·N 키 안내 문장 확인.

## 8. 코드와 참고 자료

- 화면·오디오: `app/_components/sky-sonata/`, 규칙·광원 검출: `app/_lib/sonata/`
