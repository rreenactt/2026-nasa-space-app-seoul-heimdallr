# Sky Sonata (들리는 하늘)

| 항목 | 내용 |
| --- | --- |
| ID | `sky-sonata` |
| 상태 | 확정 |
| 담당 | |
| 출력 종류 | audio |
| 최소 SPHEREx 방문 횟수 | 1 (변화 알림은 2 이상) |
| 적용 대상 | 모든 좌표 |
| 화면 배치 | 추가 분석 목록 · 키보드 접근 지원 |
| 난이도 | 하 |
| 예상 소요 시간 | 즉시 (브라우저에서 생성) |

## 1. 무엇을 알려주나

하늘의 변화를 소리로 들려준다. 위치는 좌우, 밝기는 음량, 높이는 음높이로 바꾸고, 변화한 점은 다른 음색으로 알린다.

## 2. 왜 필요한가

화면을 보기 어려운 사용자도 하늘 탐색에 참여할 수 있다. 적은 개발량으로 확실히 다른 결과물이고, 접근성이라는 별도 심사 관점을 확보한다.

## 3. 입력 데이터

- 기본 분석 결과: 블링크 시퀀스(방문별 컷아웃)
- Gaia DR3 (알려진 별 구분)

## 4. 방법

1. 블링크 시퀀스의 천체 위치·밝기를 추출한다.
2. Web Audio로 스테레오 오디오를 만든다 (좌우 = 위치, 음량 = 밝기, 음높이 = 높이).
3. 방문 사이에 변한 점은 다른 음색으로 재생한다.
4. 키보드만으로 하늘 조각을 탐색할 수 있게 한다.

## 5. 출력

- **한 줄 요약 예시:** "소리로 재생 · 변화한 점 1개 (다른 음색)"
- **audio:** 재생/정지, 재생 길이 조절
- 재생 중인 위치를 이미지에 동기화해 강조한다.

## 6. 실행 조건과 한계

- 소리가 나므로 재생 전 안내하고, 이어폰 사용을 권장한다.
- 스크린 리더와 키보드 조작을 함께 고려한다.

## 7. 검증

변화가 확실한 테스트 대상(소행성 후보, 변광성)에서 변화음이 들리는지 확인한다.
