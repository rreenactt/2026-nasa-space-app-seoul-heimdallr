# Sky Sonata (들리는 하늘)

| 항목 | 내용 |
| --- | --- |
| ID | `sky-sonata` |
| 상태 | **1차 구현됨** (분석 패널 "Additional analyses"에서 열림) |
| 담당 | 김재현 (`rreenactt`) |
| 출력 종류 | audio |
| 최소 SPHEREx 방문 횟수 | 1 (A·B 비교는 2 이상) |
| 적용 대상 | 모든 좌표 |
| 화면 배치 | 추가 분석 목록 → "Run" → 다 받으면 패널 왼쪽 탭으로 열림 (결정 #42), 키보드만으로 조작 가능 |
| 데이터 | IRSA SPHEREx DR1, AWS L2b 바이트 범위 |

## 1. 무엇을 알려주나

SPHEREx 영상 속 광원을 정해진 규칙에 따라 소리로 바꿔 들려준다. 위치는 좌우와 음높이, 밝기는 음량이 된다. 같은 지점의 두 관측(A·B)을 같은 규칙으로 이어 들어, 자리를 옮기거나 밝기가 바뀐 광원을 귀로 비교할 수 있다.

## 2. 왜 필요한가

- 화면을 보기 어려운 사용자도 하늘 비교에 참여할 수 있다 (접근성).
- 소리는 규칙을 공개한 변환이라, "우주에서 녹음한 소리"로 오해하지 않게 화면 맨 위에 적는다.

## 3. 입력 데이터

- Fake Planet Lab과 같은 경로로 찾은 SPHEREx DR1 노출의 원본 픽셀: IMAGE, ZODI, VARIANCE, FLAGS, WCS-WAVE
- 기본 A·B: 같은 검출기(D3 우선)의 첫 방문과 마지막 방문 노출
- 저장하지 않는다.

## 4. 방법

1. **광원 찾기 (원본 픽셀, 화면 대비와 무관):** IMAGE − ZODI − 하늘 중앙값(3σ 클리핑)에서 5σ 이상 봉우리이면서 3×3 합도 S/N ≥ 5인 점. 밝기는 3×3 합(mJy).
2. **플래그:** NONFUNC·MISSING_DATA·HOT·COLD는 건너뛰고, TRANSIENT·SNOWBALL은 봉우리로 쓰지 않는다. 포화 픽셀이 이어진 영역은 하나의 "포화 광원"으로 묶는다(Barnard's Star 핵 57픽셀 → 1개).
3. **소리 규칙 (`sonata-rules-1`, 고정·화면에 설명):**
   - 좌우 = 2x − 1
   - 음높이 f = fMin·(fMax/fMin)^(1−y), 위가 높음 (기본 220–1760 Hz)
   - 음량 = 밝기의 로그 압축 (상한 있음)
   - 가로 위치 = 스캔 시점 (기본 6초에 왼쪽 → 오른쪽)
   - 포화 광원은 네모파(밝기 신뢰 불가), 자료 없음은 낮은 이중 클릭
4. **A·B 비교 (규칙 `sonata-compare-1`, `app/_lib/sonata/compare.ts`):** 두 노출을 같은 규칙과 **공유 밝기 범위**(A·B 광원을 합쳐 계산, 각자 정규화하지 않음)로 재생한다.
   - **기본 A·B:** 블링크와 같은 계획(`/api/blink/plan`)에서 첫 방문과 마지막 방문의 **같은 파장** 노출을 고른다(절대 원칙 3). 계획이 없으면 각 방문 가운데 노출을 쓰고, 두 노출의 파장이 대역폭 밖으로 다르면 경고한다.
   - **광원 짝짓기:** A·B 광원을 하늘 위치로 짝짓는다(9.3″ = 1.5픽셀 이내, 포화 광원은 18.5″). 한쪽에서 S/N 10 이상인 광원만 목록에 넣는다.
   - **분류:** `About the same` / `Brighter in B`·`Fainter in B`(밝기 1.5배 이상이면서 5σ 이상 차이) / `Only found in A`·`Only found in B`(다른 쪽 9.3″ 안에 5σ 광원 없음) / `Saturated`(밝기 비교 불가, 짝이 없어도 "없음"으로 치지 않음). 차이 목록일 뿐 검출이 아니라고 적는다.
   - **광원별 비교 재생:** 광원마다 A 음 → 0.45초 뒤 B 음을 같은 음높이·같은 좌우로 잇달아 낸다. 달라지는 것은 음량뿐이라 밝기 차이가 바로 들린다. 한쪽에 없으면 낮은 틱 소리. 한 번에 최대 12개(차이 나는 것 먼저, 나머지는 밝은 순), 왼쪽 → 오른쪽 순서. "Only the differences"는 차이 나는 광원만 낸다.
   - **한 점 비교:** 영상의 아무 곳이나 누르면 그 자리를 A로, 이어서 B로 들려주고 두 밝기를 문장으로 적는다.
   - 영상 전체 스캔(A 또는 B)은 접힌 영역으로 옮겼다. 스캔 시간은 관측 시간과 다르다고 적는다.
5. **접근성:** 재생 버튼·영상 클릭·방향키를 누르면 소리가 켜진다("Start sound"를 따로 누르지 않아도 됨, 아무것도 누르지 않으면 소리 없음), 낮은 기본 음량, 항상 보이는 "Stop all sound". 영상에 초점을 두고 방향키로 지점 이동(Shift = 작은 걸음), Enter로 다시 듣기, N/P로 다음·이전 광원. 모든 소리를 `aria-live` 문장과 텍스트 광원 표로도 제공. 모노 모드.
6. **연습:** 좌·우, 위·아래, 같은 자리의 어두움·밝음 세 가지 합성 예제. "Synthetic practice — not observation data"로 구분한다.

## 5. 출력

- **탭:** Listen / Practice / Rules & sources
- **Listen:** 맨 위에 비교 버튼("Compare source by source", "Only the differences")과 결과 한 줄 요약, A·B 영상 나란히(짝 종류별 색 ×표: 노랑 같음, 분홍 밝기 다름, 청록 한쪽만, 주황 포화), 광원별 A 대 B 표(행마다 "A → B" 재생), 접힌 영역에 전체 스캔과 소리 설정
- 재생·정지, 스캔 길이·음높이 범위·모노 설정, 재생선 표시
- 광원 표와 소리 이벤트 JSON 복사, 공유 링크 `/?sonata=ra,dec,fMin,fMax,scan,mono,fluxLo,fluxHi`

## 6. 한계와 주의

- 재생할 광원 수에 상한이 있다. "소리 없음 ≠ 빈 하늘"이라고 적는다.
- 광원 짝짓기는 3×3 합 밝기와 위치만 쓴다. PSF 차이, 픽셀 위상, 허용치 안의 파장 차이로도 "다름"이 나올 수 있어 볼 곳의 목록으로만 쓴다. 변한 점을 다른 음색으로 알리지는 않는다.

## 7. 검증

- 규칙 시험: 좌우만 다른 두 점 → pan −0.8/+0.8(음높이·음량 같음), 위아래만 다른 두 점 → 1430/271 Hz, 밝기만 다른 두 점 → 음량 0.07/0.29, 같은 영상을 A·B로 넣으면 이벤트가 완전히 같음.
- A·B 비교 (2026-11-15, RW Aurigae 시야 D3): 기본 A·B가 같은 파장(약 2.152 µm)의 2025-09-18·2026-02-21 노출로 잡힘(이전 기본값은 2.199·1.677 µm로 대역폭 밖). 짝 14개: 같음 9, 한쪽만 3(A만 2, B만 1), 포화 2로 표시되었고(비교 재생은 그중 12개) 광원별 비교 재생 중 안내 문장과 십자 표시가 광원을 따라감을 확인. 이때 RW Aurigae 자신이 "A에만 있음"으로 나와(포화 영역이 B에서는 광원으로 잡히지 않음) 포화 광원은 "비교 불가"로 분류하도록 고쳤다. 고친 뒤: 같음 9, A만 1, B만 1, 포화 3. 소리 자체는 사람이 들어 확인해야 한다(자동 확인은 예약·안내 문장·표시까지).
- 브라우저: 스캔 시 15음 예약·재생선 표시, 정지 시 남은 예약 11음 즉시 취소, A→B 15+13음 순서 재생, 방향키·N 키 안내 문장 확인.
